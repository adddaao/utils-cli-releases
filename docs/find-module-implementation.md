# Find 模块实现总结

## 已完成的功能

### 1. 通用 SQLite 数据库组件 ✅
- **位置**: `internal/database/db.go`
- **功能**:
  - 自动管理数据库连接（单例模式）
  - 支持 WAL 模式
  - 线程安全操作
  - 支持事务和迁移
  - 自动创建数据库目录
  - 支持调试/生产模式路径

### 2. Find 模块核心组件 ✅

#### 2.1 命令构建器 (`internal/find/builder.go`)
- 从 `FindQuery` 结构生成 find 命令字符串
- 支持所有常用 find 参数：
  - 路径、类型、深度限制
  - 名称匹配（name/iname/regex）
  - 大小过滤（支持 +、-、= 操作符）
  - 时间过滤（mtime/atime/ctime，支持天数/分钟）
  - 权限过滤（perm/readable/writable/executable）
  - 用户/组过滤（user/group/uid/gid）
  - 空文件/目录（empty）
  - 执行动作（print/delete/exec/exec+/ok/ls）
- 自动处理路径和值的引用（处理空格和特殊字符）

#### 2.2 命令执行器 (`internal/find/executor.go`)
- 执行 find 命令并捕获输出
- 支持预览模式（移除危险操作进行测试）
- 自动保存执行历史到 SQLite
- 检测危险操作（delete/exec）

#### 2.3 模板管理器 (`internal/find/templates.go`)
- 10 个内置预设模板
- 支持模板的增删改查
- 支持自定义模板（待实现持久化）

#### 2.4 历史记录管理 (`internal/find/history.go`)
- 使用 SQLite 存储历史记录
- 支持添加、查询、删除历史记录
- 支持按路径搜索历史记录
- 自动创建数据库表和索引

### 3. Find TUI 界面 ✅

#### 3.1 主菜单
- 自定义构建查询
- 使用预设模板
- 查看历史记录

#### 3.2 自定义构建流程（5步向导）
1. **步骤 1: 选择搜索路径**
   - 输入路径（支持默认值）
   - 常用路径提示

2. **步骤 2: 选择文件类型**
   - f=文件, d=目录, l=链接等
   - 留空表示所有类型

3. **步骤 3: 选择过滤条件（可多选）**
   - 名称匹配（name/iname）
   - 大小过滤（size）
   - 修改时间（mtime）
   - 空文件/目录（empty）
   - 可执行文件（executable）
   - 用户过滤（user）
   - 空格键选择/取消
   - Enter 设置条件详情

4. **步骤 4: 选择执行动作**
   - print（默认）
   - delete（危险操作）
   - exec/exec+/ok（需要输入命令模板）
   - ls

5. **步骤 5: 预览和执行**
   - 显示生成的命令
   - Enter 执行
   - 显示执行结果

#### 3.3 模板选择流程
- 显示所有预设模板列表
- 选择模板后自动生成命令
- 预览命令
- 执行命令

#### 3.4 历史记录流程
- 显示最近 20 条历史记录
- 显示命令、路径、结果数、状态
- Enter 查看详情
- 支持重新执行历史命令

## 数据库设计

### 历史记录表
```sql
CREATE TABLE find_history (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    command TEXT NOT NULL,
    path TEXT NOT NULL,
    result_count INTEGER DEFAULT 0,
    success INTEGER DEFAULT 1,
    error_msg TEXT,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP
);

CREATE INDEX idx_find_history_created_at ON find_history(created_at DESC);
CREATE INDEX idx_find_history_path ON find_history(path);
```

## 使用流程示例

### 示例 1: 查找大文件
1. 进入 Find 模块
2. 选择 "自定义构建查询"
3. 步骤 1: 输入路径 `.`
4. 步骤 2: 输入类型 `f`
5. 步骤 3: 选择 "大小过滤"，输入 `+100M`
6. 步骤 4: 选择动作 `print`
7. 步骤 5: 预览并执行

生成的命令: `find . -type f -size +100M -print`

### 示例 2: 使用模板
1. 进入 Find 模块
2. 选择 "使用预设模板"
3. 选择 "查找大文件" 模板
4. 预览命令
5. 执行

### 示例 3: 查看历史
1. 进入 Find 模块
2. 选择 "查看历史记录"
3. 查看历史列表
4. Enter 查看详情或重新执行

## 技术实现要点

### 1. 状态管理
- 使用状态机管理复杂的交互流程
- 每个步骤都有独立的状态
- ESC 键统一处理返回逻辑

### 2. 条件选择
- 支持多选（空格键切换）
- 显示选中状态（[x] / [ ]）
- 条件值独立存储和显示

### 3. 命令构建
- 实时构建命令字符串
- 处理特殊字符和空格
- 支持复杂的条件组合

### 4. 命令执行
- 异步执行长时间运行的命令
- 实时显示执行结果
- 自动保存到历史记录

### 5. 错误处理
- 友好的错误提示
- 验证输入有效性
- 处理执行失败情况

## 已知限制

1. **模板持久化**: 自定义模板目前只保存在内存中，重启后丢失
2. **结果分页**: 大量结果时只显示前 50 条
3. **命令验证**: 目前不验证命令语法，直接执行
4. **Windows 支持**: find 命令在 Windows 上需要 Git Bash 或 WSL
