# Docker 删除确认与问题总结

## 镜像删除

在“查看镜像列表”及其镜像详情弹框中，连续两下 `d` 才受理删除。第一次只登记当前目标，信息展示区说明标签与占用风险，待确认状态一直保留到下一次按键；第二次 `d` 才继续。移动光标、其他按键、鼠标操作或离开页面会取消待确认状态。导出、上传的镜像选择页不提供删除快捷键。

单标签镜像在第二次 `d` 后执行。多个标签合并为一行时，第二次 `d` 打开范围选择：

| 选项 | 删除范围 |
| --- | --- |
| 选择标签删除 | 使用公共多选弹框；`Space` 勾选，`r a` 全选或取消全选，`Enter` 提交范围。没有勾选时仅提交当前标签。 |
| 删除全部 | 当前镜像分组中的全部标签。 |
| 只保留最新 | 按 Docker 返回的镜像创建时间保留最新镜像及其全部标签，删除较旧镜像；并列最新的镜像全部保留。 |

选择范围不会立即删除。确认弹框完整展示实际标签集合，`Enter/y` 确认执行，`Esc/q/n` 取消。长列表使用公共只读确认组件固定表头与确认按钮，支持方向键、翻页键及滚轮查看。缩放、焦点变化不会改变已选集合。

“只保留最新”不按标签名称、版本号或标签 `latest` 猜测。存在缺失的创建时间，或本组全部为最新镜像时，提示具体原因并停留在选项弹框。

镜像逐标签串行删除，不强制删除；一个标签失败后继续处理其余标签。进度显示当前标签与已处理数量。仍被容器引用的镜像由 Docker 拒绝删除，程序不会自动移除相关容器。

## 删除结果

执行完成后在原执行弹框内展示：

1. 删除汇总：成功、全部失败或部分失败及对应数量。
2. 问题总结：按原因归类，统计受影响标签数。
3. 逐标签结果：完整标签、精简具体错误及处理建议。

例如 daemon 返回 `container 244e54f055c9 is using its referenced image` 时，问题总结显示“镜像仍被容器引用”，具体错误显示“容器 244e54f055c9 仍引用该镜像，无法删除”。权限不足、镜像不存在、关联引用、取消、超时、连接失败也分别总结；未知错误保留具体文本，不用通用提示替代。

默认收起原始错误，`v` 显示或收起；方向键、翻页键和滚轮查看完整结果，`Alt+↑/↓` 按表格标题跳转。执行日志保留精简原因、处理建议及 daemon 原始错误。关闭结果后刷新镜像列表。

## 其他删除入口

“清理已退出容器”选择条目后先展示具名二次确认弹框，取消保留勾选，确认后才执行。容器工作台删除继续复用操作确认弹框；资源清理继续通过范围表单的确认按钮执行。可信远端源、清理模板、部署映射和结构化编辑记录等已有删除入口沿用公共 `deleteconfirm.Guard` 的双键确认。

## 验证

执行 `make test-docker-deletion` 验证精简错误、范围选项、二次确认、最新镜像与标签别名、逐标签进度及失败后继续。执行 `make test-tui` 验证公共组件、模块与真实 Shell 的帮助授权、按键分发及缩放。测试使用模拟数据和隔离 HTTP Docker 服务，不删除真实镜像或容器。
