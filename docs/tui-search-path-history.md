# 表格搜索与近期路径候选

## 表格搜索

普通列表、公共表格和选择弹框的搜索框默认隐藏，只在按 `/` 后展开并聚焦；唯一常显搜索入口是 F4 命令面板。结构化列表复用 `components/search.TableSearch`，统一页面负责真实光标、点击坐标及高度。输入同步筛选，`Enter` 应用并收起，`Esc` 清空并收起，`Tab` 返回列表并收起；收起后释放输入行，保留已应用筛选及按身份记录的勾选。再次按 `/` 继续编辑查询。操作说明只在底部帮助栏显示，搜索文字和粘贴不会触发删除、返回或编号动作。

搜索按关键词的模糊子序列匹配，多个以空白分隔的关键词同时满足才保留，保持原表格排序和按行身份记录的勾选。输入后同步应用结果，不发出旧版未绑定查询词的异步筛选消息；表格模式忽略迟到的旧筛选结果，减少快速输入时旧结果覆盖和选中行跳动。窗口缩放、列表重建和排序保留当前搜索词。

公共 `list.TableDelegate` 自动声明支持按需搜索；其他结构化 delegate 实现 `SupportsTableSearch() bool`，由 `UnifiedPageModel.SetListDelegate` 统一启用或关闭。需要额外搜索字段的条目实现 `SearchValue() string`；`FilterValue()` 继续作为稳定的行身份，不能为了扩大搜索范围而改变它。`SetTableSearchEnabled` 也可供统一页面的专用列表显式接入。

Docker 的查看、导出、上传镜像列表已经接入；镜像名、合并行内所有标签及镜像 ID 都参与匹配。搜索后仍能排序、勾选和选择标签。

普通 `ModalListModel`（含简单部署容器下拉）同样先按 `/` 展开搜索；字母、数字、中文、emoji、粘贴以及 `q/j/k` 均作为查询。方向键定位，`Enter` 应用查询并收起输入，再次 `Enter` 确认候选；`Esc` 在搜索态清空查询并收起。候选仍保留原始提交值。只有 F4 命令面板调用 `SetSearchInputEnabled(true)` 常显并立即聚焦搜索，保持一次 `Enter` 跳转、一次 `Esc` 取消。

## 文件路径类型

必须选择具体文件的字段使用公共 `form.ParameterFormKindFilePath`，类型列显示“文件路径”，沿用路径内联编辑与真实光标；默认要求存在且为普通文件，目录仅用于导航，不能作为最终值提交。映射配置导入已接入此类型，例如 `./deploy-archive.conf`；该表单隐藏普通配置信息区，将空间留给输入与文件候选，短操作反馈仍由 Shell 显示。

候选通过同一个 `path.SuggestionContext` 设置 `FileInput = true`，在目录候选中加入普通文件；目录候选保留尾部分隔符，文件候选保留完整文件名。补全、选择、渲染和近期记录均沿用公共路径方法，普通路径模式继续只提供目录候选。AIOps 统一根据字段的文件校验策略启用文件模式，既有“文件”字段也可获得文件补全。

## 近期路径候选

路径历史保存到 `<data_dir>/tui/path-history.toml`，由 `internal/store.PathHistory` 统一读取、私有权限写入和原子更新。目录权限为 0700，文件为 0600。每条记录包含模块、用途、路径和最近确认时间。

- 模块与用途必须同时匹配，不把 Docker 导入来源混入简单部署的目标目录，也不混用同模块内不同用途。
- 候选依次来自同场景最近确认过的路径、当前配置提供的路径、文件系统匹配项；相同路径去重，空输入也能看到近期及配置候选。
- 历史有效期为 30 天，每个场景最多 50 条，总记录最多 1000 条。再次确认会刷新时间并置顶；过期记录不再显示，并在后续写入时收缩文档。
- 当前配置中的路径可继续作为候选，不受历史时间限制。历史路径以绝对路径保存，避免切换工作目录后指向错误位置。
- 只记录已确认的字段或路径选择结果；按取消离开的草稿不记录。历史读取或保存失败会写日志，保留当前输入流程。

模块通过 `path.NewSuggestionContext(module, scope, dataDir, configuredPaths)` 提供明确场景。独立选择器使用 `SelectorOptions.Context`；内联路径编辑把同一个上下文传给候选查询、渲染、移动、补全和回填方法，并在字段验证成功后调用 `Remember`。不能自行读取历史文件或在每次按键时保存草稿。

已接入 AIOps 路径表单、简单部署交付源与映射目标、Docker 镜像导入、运行配置挂载路径、离线下载输出和离线安装目录。集中补齐制品配置时，前一项刚确认的目标路径会优先出现在后一项的建议中。

## 验证

`make test-tui` 覆盖搜索框点击及粘贴、模糊匹配全部标签、旧结果隔离、稳定帧、真实行点击、排序/勾选和缩放，以及路径确认/取消和下一制品复用、文件路径类型校验、文件候选与目录导航、中文/emoji 文件名和相对路径补全。`make test-store` 覆盖历史持久化、过期、数量上限、用途隔离、访问权限和损坏文档保护。自动回归不代替用户终端上的视觉体验验收。
