# 工作台视觉、前缀提示与功能搜索

本文定义工作台统一视觉及只做页面导航的命令面板。正式文档入口见 [文档索引](README.md)，公共组件接入规则见 [组件清单](../internal/tui/components/README.md)。视觉组织参考 [sqlmux](https://github.com/kackerx/sqlmux) 的焦点层次与操作提示，继续沿用本项目的三栏工作台、公共组件和终端兼容渲染器。

## 统一视觉

- 最终全屏视图仍由 `theme.ApplyWorkbenchTheme` 覆盖固定黑底（ANSI256 扩展色 16）与默认正文（252）；模块不设置整行背景或反显。
- `theme` 集中定义强调、当前项、勾选、编辑、辅助、边框、成功和错误等语义颜色。正文、表头与帮助说明沿用默认前景色，表头保留粗体和仅覆盖文字的下划线。
- 配色完整保留：强调色 62、选中色 226、辅助灰色 245、编辑色 205、成功 46、错误 196，黑底 16 与正文 252 不变。导航与列表失焦时全部条目和勾选统一灰化，导航来源标记 `◆` 继续保持亮色。sqlmux 只用于参考排版与标题组织，不引入其主题色。
- 边框颜色保持原样：工作区及弹框聚焦边框为蓝紫色（62），普通面板与表单边框为灰色（240），错误和成功框沿用原颜色。表单不因当前字段而改变整框颜色。
- 面板、表单、字段说明、提示框和弹框共用 `theme.RenderTitledPanel`，标题嵌在上边框。工作台与弹框使用直角细边框，标题不另占内容行，也不使用背景色条；背景仍由最终工作台统一处理。弹框保留标题下的一行间距，鼠标与搜索光标坐标保持稳定，框外来源内容继续可见。
- 表单保留“字段 / 值 / 类型”结构及原有正文、选中、编辑和错误配色。操作行由公共组件显示为 `[ 执行 ]`、`[ 保存 ]` 等按钮，沿用原来的 Enter 分发和校验。优化集中在边框标题、说明区、间距和按钮形态。
- 保留面包屑及其导航、左侧模块栏、按需显示的信息区和底部帮助。快捷键说明只放在帮助区。

公共表格采用 C 布局：标题嵌入上边框，列间细竖线，表头下横线。只读详情和结构化列表共用该规则；完整详情在窄窗继续保留字段并换行。普通列表和选择弹框只在按 `/` 后展开搜索，收起后释放高度；只有 F4 命令面板常显搜索。具体输入契约见 [表格搜索](tui-search-path-history.md)。

## `r/R` 前缀提示

进入前缀等待后，底部帮助区展示“第二键 / 操作”表格。候选由当前可见 `HelpBinding` 与原有前缀授权共同生成；区分第二键大小写，不展示隐藏或未授权动作，不建立独立快捷键表。无模块弹框时继续提供 Shell 的 `r q` 返回导航栏。

前缀操作表与状态最多占可用窗口高度的三分之一。候选过多时用 `PgUp/PgDn` 翻页，翻页不取消前缀、不执行来源页动作；第二键仍直接触发原动作，`Esc` 只取消前缀。底部保留实际输入前缀、等待状态和分页提示。

保留既有单键回退、输入法批量提交防护、大小写修饰键等待及短反馈延迟关闭。文本编辑、搜索和粘贴优先接收原文；取消、完成、页面切换及超时后恢复普通帮助。鼠标事件取消前缀并消费本次事件。

## F4 功能搜索

在允许导航的页面按 `F4` 打开命令面板，打开即聚焦搜索框；面板显示期间再按 `F4` 关闭并保留来源页面，帮助栏显示 `F4 关闭功能搜索`。候选显示功能名称、所属模块和稳定 ID；三者均可搜索，使用公共同步模糊匹配并保持目录顺序。

| 输入 | 行为 |
| --- | --- |
| 文字、数字、中文、emoji、粘贴 | 编辑搜索词；`q/j/k` 是普通文字 |
| `↑↓` | 页内定位候选，跨页边界时切页 |
| `PgUp/PgDn` | 上一页/下一页；保留搜索词及页内位置，末页保留完整候选窗口 |
| `←→/Home/End`、`Backspace/Delete` | 编辑搜索词 |
| `Enter` | 确认并进入页面；空结果不执行 |
| `Esc` | 一次取消，返回来源页 |
| 左键、滚轮 | 只定位或滚动面板，不确认、不关闭、不穿透 |
| `Ctrl+C` | 沿用全局退出 |

面板使用公共 `ModalListModel`，显式偏上居中、宽度受内容区及公共 96 列上限约束，输入与真实光标使用公共搜索组件。取消保留来源页焦点、筛选、排序、勾选与滚动；确认后聚焦内容区并更新导航、面包屑与帮助。

命令面板通过公共 `SetPaginationEnabled(true)` 开启整页候选窗口。页内移动不再使候选居中滚动；候选超过一页时显示当前页、总页数及条目范围。搜索、缩放和鼠标命中仍由公共列表处理，左右键继续编辑搜索光标。

### 导航目录与状态保护

复用 `StarCatalog` 的模块及子功能 ID。子功能必须在 `StarFunction.PaletteNavigation` 中显式声明；默认不加入面板。立即执行容器日志清理这类写操作不允许加入。进入参数页的导出、部署、安装等入口可以加入，真正执行仍沿用来源模块的确认流程。

内置模块实现 `CommandNavigationGuard.CanNavigateCommands()`。首版采用保守规则：普通模块主菜单可导航，Docker 额外开放未在筛选或删除等待中的只读镜像列表。编辑、参数页、确认、弹框、阻塞任务和短反馈期间不开放；这些状态下不显示 F4 提示。未实现守卫的模块只有显式声明的根页可用，未知状态默认不可用。

打开面板时检查来源及目标模块状态；确认时重新生成目录并再次检查，防止目标模块中的草稿或任务被重置。目标失效时留在面板并显示公共错误提示；提示按弹框实际宽度重新排版。关注导航与命令面板复用按目标 ID 导航的入口；导航启动的异步结果定向返回所属模块，不改变用户后来切换到的可见模块。

本功能不增加配置项、搜索历史持久化或数据迁移。取消面板不写配置。

## Docker 镜像列表样板

镜像表格复用公共搜索、列宽、排序与选择状态。去掉镜像行之间的额外空行，同页行高按最长换行行统一补齐，大小列右对齐；详情继续完整显示字段。

查看、导出、上传镜像列表确认排序时，光标保留在当前可见行的位置，不跟随原镜像跳到其他行或页；筛选词、按镜像身份记录的勾选及提交集合保持不变。筛选后的位置以筛选结果为准。数据刷新和标签勾选后的重建仍按镜像身份保留当前项。

同一列表刷新保留筛选、已确认排序、当前行和仍有效的标签勾选；刷新时取消旧的删除等待及临时弹框，已经不存在的标签不保留。切换到新的导出、上传或普通查看流程时重置上一流程的选择与筛选。普通浏览隐藏例行摘要，删除影响与操作结果继续显示。

## 验证

所有验证均通过 Makefile：`make test-tui-navigation` 验证导航、前缀和镜像刷新；`make test-tui` 包含公共组件、所有模块及固定渲染器回归；`make test-docker-deletion` 与 `make test-devwatch` 验证删除和开发会话兼容。

`make tui-style-preview` 使用真实 Shell、公共表单和命令面板导出 `build/style-preview/` 下的终端单元格与 PNG。Python 依赖通过 uv 临时环境提供，不写入工程缓存；预览使用虚构参数，不读取连接、凭证或业务数据。图片帮助检查排版，真实终端行为仍以连续程序输出及独立 VT 回放为准。

`make tui-header-options` 在 `build/header-options/` 导出镜像列表搜索区和表头的四个候选布局。候选仅用于视觉选择，复用现有表格列宽及配色，不接入正式页面，也不创建主题配置；C 为已选方案，正式公共表格已采用该布局。`make tui-table-preview` 导出当前真实公共组件的默认列表、搜索展开和只读表格画面。

真实 Bubble Tea 程序连续输出经独立 VT 回放，覆盖文字、每格背景、可见文字前景、粗体/下划线、真实光标、中文/emoji 输入、鼠标、取消/确认、重复聚焦、重复尺寸与往返缩放。普通交互不得新增清屏、硬滚动、硬 Tab 或退格定位。该验证不代替 Xshell、Windows Terminal 等外部客户端的人工验收。
