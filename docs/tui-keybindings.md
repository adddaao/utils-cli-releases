# TUI 按键规范

本规范描述实施后的按键语义。历史盘点和改造前的问题保留在[按键审计快照](tui-keybinding-inventory.md)。页面实际可用键以当前状态的底部帮助栏为准：模块通过 `GetHelpBindings` 声明，Shell 使用同一声明授权分发。未声明的模块动作不得执行。

普通列表、表格及选择弹框仅按 `/` 展开搜索。表格搜索按 Enter 应用并收起、Esc 清空并收起、Tab 返回列表；普通弹框确认搜索后再次 Enter 选择候选。只有 F4 命令面板始终显示并聚焦搜索，一次 Enter 跳转、一次 Esc 取消。详见 [搜索契约](tui-search-path-history.md)。

## 通用规则

| 键 | 条件与动作 |
| --- | --- |
| `Ctrl+C` | 强制退出程序；任意状态（含弹框）都生效，是唯一的退出入口，`q` 不再退出 |
| `F4` | 在允许导航的菜单与只读页面打开功能搜索；打开即输入，`↑↓/PgUp/PgDn` 定位、`Enter` 跳转、`Esc` 取消，再次按 `F4` 关闭。编辑、搜索、弹框、参数草稿或阻塞任务期间不可用 |
| `a` | 当前页已有且唯一的新增动作；多个不同新增目标仍由菜单选择 |
| `d` | 当前选中项已有删除流程时删除，且必须连续两下 `d` 才真正执行：第一次只进入待确认并把帮助栏说明改成“再按一次删除”，待确认状态会一直保留到下一次按键；其他按键、光标移动、页面切换会取消；页面有信息展示区时同时显示待删除目标与影响范围。不可恢复的写操作不得用单次 `d` 直接执行，也不再单独增加确认页 |
| `s` | 仅可标星功能菜单切换关注；列表筛选或文本输入时作为文字输入 |
| `i` | 当前项已有完整详情或明细时打开详情；该展示层显示期间再按 `i` 关闭（帮助栏显示 `i 关闭…`） |
| `c` | 当前页有可复制的只读结果（密码、命令、转换结果等）时复制：桌面会话写本机剪贴板，SSH 会话或无桌面会话回退终端 OSC 52；两条通道都不可用时不得声明该键 |
| `S` | 当前列表或弹框内表格支持多列排序时打开排序弹框（可覆盖在镜像详情、选择标签弹框之上）；弹框显示期间再按 `S` 关闭并取消未确认的排序；弹框内 `Space` 加入/移出排序、`←→` 切换升/降序、`Shift+↑↓` 调整优先级、`Enter` 应用、`Esc/q` 取消保留原排序。搜索输入态下 `S` 是查询字符 |
| `r s` | 保存或测试并保存；不用于开始、提交、下载、导入和执行 |
| `Enter` | 确认当前选项或触发可见操作行；执行动作保留确认页或确认弹框 |
| `r t` | 当前参数表单支持预检时只测试，不保存 |
| `↑/↓`、`k/j` | 列表上/下循环选择；筛选输入时由筛选组件接收 |
| `Tab`、`Shift+Tab` | 导航栏聚焦时切到内容区；内容区聚焦时不切回导航栏，只有当前状态显式声明 `Tab`/`Shift+Tab`（路径补全、表单区块切换等）时才下发给模块 |
| `←/→` | 列表页确实多于一页时整页翻动（等价 `PgUp/PgDn`，帮助栏显示 `←→ 翻页`）；模块自己声明 `←/→`（表格横向滚动、光标移动、排序方向）时以模块声明为准；未声明时在内容区任何状态（含模块根页）都把焦点交回左侧主界面（模块选择），帮助栏显示 `←→ 返回导航栏` |
| 数字 | 定位列表项，支持多位编号，之后仍需 `Enter`；字母动作优先于编号缓冲 |
| `Space` | 只在已声明的多选列表或可切换字段上勾选、切换 |
| `r a` | 多选列表或弹框全选/取消全选：当前可见项全部已勾选时清空全部勾选，否则勾选全部可见项；小写 `a` 只表示新增，不得再作为全选的等效键 |
| `q` | 内容区逐级返回：模块声明了 `q` 就交模块返回上一级；未声明（含模块根页）时等同 `r q` 回到左侧导航栏，帮助栏必须显示该 `q`。导航栏聚焦时不退出程序，只在模块声明了 `q` 且不在根状态时返回当前流程；退出程序统一由 `Ctrl+C` 承担 |
| `Esc/q` | 只在当前状态声明时返回或取消；`r q` 保留为返回左侧导航栏的显式入口 |
| `o/O`、`r o/r O` | 当前状态已登记生成物且本机图形会话可用时打开文件夹（`o/O`）、文件（`r o/r O`） |

表中 `r` 开头的按键均为 `r` 前缀两键序列，规则见下节「r 前缀两键序列」。

由单个按键打开的只读展示层一律是开关：详情、预览、明细、排序弹框和功能搜索在显示期间再按同一按键即关闭，等价 `Esc/q`。覆盖层用 `ModalListModel.SetToggleClose(开关键, 帮助说明)` 登记（排序弹框用 `sorting.Picker.SetToggleClose`），Shell 从当前弹框自动派生帮助栏的 `<键> 关闭…`，模块不得在每个弹框态手写关闭键；覆盖层进入搜索输入态后，可打印字符仍作为查询内容，不能关闭覆盖层。新增覆盖层必须验证“打开 → 同键关闭”，并检查关闭后来源页状态、光标、勾选与滚动不变。

详情与日志 viewport 的键盘滚动仅接受帮助栏声明的 `↑/↓`、`k/j`、`PgUp/PgDn`、`Home/End`；鼠标滚轮仍可滚动。`Space/f/b/u/d/h/l` 不再触发库自带的隐藏 viewport 动作。列表库自带的 `?` 全帮助已关闭，帮助信息统一显示在底栏。

不可恢复的删除统一走公共 `internal/tui/components/deleteconfirm`：两次 `d` 必须指向同一目标；第一次按键登记目标，待确认状态不设自动超时，会一直保留到下一次按键，第二次按键才执行删除；其他按键、光标移动、鼠标事件和页面切换都必须取消待确认。模块在第一次按键后把该动作的绑定改为 `shell.NewDoublePressHelpBinding("d", "再按一次删除", "d")`，有信息展示区的页面同时展示待删除目标与影响范围；第一次按键前的绑定显示为 `dd`，可见键仍是 `d`。Shell 对声明为双击确认的字母不做防抖延迟、也不吞掉同字母的第二次按键，避免快速连按被输入法防抖吃掉；中间夹有其他字母的拼音串仍按连续输入整段忽略。

中文输入法开启时，字母和数字会在组合完成前被输入法截获，`s`、`j/k`、`q`、数字等快捷键不会到达应用；这是终端输入法行为，应用无法读取拼音组合串。应用侧只做两件事：把提交的全角 ASCII（`１`、`ｓ`、全角空格等）归一化成半角后再参与快捷键与编号定位；非编辑态收到提交的中文时直接丢弃；成批英文输入只按下述长度规则处理，不能逐字符提前执行；输入法组合开始前偶尔泄漏到应用的单字母同样静默忽略，不再出现“只允许输入数字编号”提示。非编辑态还会把快速连续到达的字母整段忽略（间隔小于约 180ms，直到静默约 350ms；`j/k` 导航与 `r` 前缀两键序列除外），避免输入法打字触发多个单字母快捷键。已声明的单字母动作会先延迟约 120ms 判定（`r` 例外，它按下面「r 前缀两键序列」的单键回退或持续等待规则判定）：这期间又收到字母就说明是连续输入，整段丢弃（第一个字母也不执行）；没有后续字母时才执行，因此单独按下的字母会有一点判定延迟。声明为连续两下确认的字母（例如 `dd` 删除）例外：第一次按键立即到达模块，同字母的第二次按键也不会被防抖吞掉，由模块判定待确认状态（不设自动超时，会一直保留到下一次按键）；中间夹有其他字母的拼音串仍按连续输入整段忽略。收到中文时于信息展示区提示“中文输入法会拦截菜单快捷键，请切换到英文输入”。终端可能把输入法一次提交的 ASCII 字节拆成多个单字符事件。全屏入口启用 `WithTextInputBatching(15ms)`：把相邻间隔小于该窗口的普通可打印按键合为一批，在动作执行前统一检查；控制键、粘贴和按住重复事件保持独立。终端没有统一可用的输入法提交边界，因此这是到达时间的判定，超过窗口会作为不同批次。非编辑态恰好两个字符时，只接受 `r/R` 开头且第二字母对应当前已声明动作的序列；其他双字符（包括 `jj`、`dd`、`11`）整批丢弃。三个及以上字符一律整批静默丢弃，无论是否以 `r/R` 开头，`rsx` 不得先执行 `rs`；分开按下的单键导航、编号和双击删除保持原规则。长度按 Unicode 字符计数，文本编辑和弹框搜索优先于此规则接收完整原文。文本编辑器和筛选输入仍按用户提交的内容原样接收，不做归一化。

## r 前缀两键序列

除 `Ctrl+C` 外，TUI 不再使用任何 Ctrl 组合键：真实的 `Ctrl+<字母>` 可能被终端截获，即使送达应用也会被 Shell 在最外层统一拦截并丢弃（`Ctrl+C` 例外），模块不需要处理。原有的 `Ctrl+S`、`Ctrl+T`、`Ctrl+A`、`Ctrl+X`、`Ctrl+D`、`Ctrl+L`、`Ctrl+E`、`Ctrl+O`、`Ctrl+Q` 等动作全部改为「先按 `r`，再按原字母」的两键序列：

| 原键 | 两键序列 |
| --- | --- |
| `Ctrl+S` | `r s` |
| `Ctrl+T` | `r t` |
| `Ctrl+A` | `r a` |
| `Ctrl+X` | `r x` |
| `Ctrl+D` | `r d` |
| `Ctrl+L` | `r l` |
| `Ctrl+E` | `r e` |
| `Ctrl+o` / `Ctrl+O` | `r o` / `r O`（打开生成物文件） |
| `Ctrl+O`（简单部署「导入映射」） | `r i`（内部改为 `ctrl+i`；不再占用 `r o`，避免与打开生成物文件混淆） |
| `Ctrl+Q` | `r q` |
| `Ctrl+U`（仅 find 条件编辑器「取消分组」） | `r u`；文本编辑态的 `Ctrl+U` 已删除 |

规则：

1. 先按 `r` 或 `R`，再按原字母；前缀不区分大小写，两个键依次按下，不按住 Ctrl，也不需要同时按。`r/R` 前缀只在内容区生效：导航栏聚焦时不进入前缀等待；文本编辑态和弹框搜索态按普通文字输入处理，不触发前缀；弹框打开时只有该弹框声明过的 Ctrl 动作可用两键序列触发。
2. 第二个字母大小写精确：`r s` 与 `r S` 是不同序列，互不替代。原帮助栏同时声明小写和大写两个 Ctrl 键的动作（生成物打开文件）显示为 `r o/r O`。
3. 当前页面声明了所按 `r/R` 的单键动作且没有计时提示时，约 300ms 内没有第二个字母就执行该单键动作（保留原大小写）；没有对应单键动作时持续等待下一键，不再空回退而让提示一闪而过。计时提示可见时按第 9 条持续等待。第二个字母对应的 `Ctrl+<字母>` 在当前状态已声明时，Shell 把它翻译成原来的 `Ctrl+<字母>` 消息交给模块处理，不再触发前缀字母的单键动作。禁止注册或触发 `rr`、`rR`、`Rr`、`RR`：第二键为 `r/R` 时只取消等待，不执行动作、不回退为单键、不重新等待；其他第二个字母没有对应声明时取消前缀，该字母继续按普通按键处理。
4. 按下 `r/R` 后，底部帮助区展示当前已授权的“第二键 / 操作”候选，保留大小写区别；最后一行显示 `已输入：r · 等待下一键（Esc 取消）` 和分页提示。展示最多占可用高度三分之一，短窗口省略标题或表头，`PgUp/PgDn` 只翻动候选。按 `Esc` 只取消前缀并恢复来源页滚动；其他非字母键取消后按普通按键处理。完成、取消、单键超时回退或切换模块后恢复普通帮助。
5. 帮助栏统一显示为「`r ` + 原字母（保持原大小写）」，例如 `r s`、`r t`、`r q`；不再出现 `Ctrl+S` 这类文案。`Ctrl+C` 仍显示为 `Ctrl+C`，是唯一保留的 Ctrl 组合键和唯一的退出入口。
6. 文本编辑态只保留 `Backspace`/`Delete` 删除字符；原来的 `Ctrl+U`（删除光标前内容）和 `Ctrl+H`（退格别名）已删除。
7. find 移动态只保留 `↑↓`、`k`、`j`；`Ctrl+↑`/`Ctrl+↓` 别名已删除。
8. Shell 把两键序列翻译成原来的 `Ctrl+<字母>` 消息再交给模块，模块内部的 `Update` 分支和 `Keys` 声明保持不变。
9. 短反馈、标星反馈或输入法提示可见时，`r/R` 跳过字母防抖，立即显示前缀等待行并持续等待真正的第二键或取消，不使用 300ms 单键回退；这不依赖终端是否上报 Shift/Caps Lock。前缀等待期间提示的到期关闭消息暂缓处理，序列完成或取消后再补发；旧消息仍按代次校验，不能关闭新提示。后台任务继续执行。
10. 单独按左/右 `Shift` 或 `Caps Lock` 只调整大小写，不触发动作、不关闭反馈；计时提示可见时即使尚未按 `r`，收到这些按键也暂缓关闭，直到真正的操作键或取消到达；释放修饰键不恢复关闭。普通前缀等待期间收到这些按键时停掉两键超时，继续等待真正的第二键或 `Esc`。Shell 从计时提示出现时就请求增强键盘事件及关联文本；支持该协议的终端会上报独立修饰键，不支持的终端只能识别最终输入的大写字母，可先按 `r/R` 保留提示。按键释放事件不参与动作。鼠标取消等待并消费本次事件；粘贴或模块切换取消等待和暂缓关闭，粘贴仍按原输入用途处理。

功能搜索的目录声明、状态守卫及取消恢复规则见 [工作台视觉、前缀提示与功能搜索](tui-command-navigation.md)。

## 状态约束

- 加载弹框只显示和接收加载期间有效的取消键；确认弹框、列表弹框按实际能力显示翻页、搜索、勾选和确认。长内容弹框显示 `Alt+↑/Alt+↓` 时可按标题跳转。
- Find 条件编辑器按空闲、字段/模板选择、值输入、移动四种状态分别声明和门控。空闲态 `a` 新增条件、`dd` 删除当前条件、`r x` 完成；分组用 `r a`、取消分组用 `r u`、清理无效用 `r l`、清空所有条件用 `r d`；移动态用 `m` 进入、只用 `↑↓/k/j` 移动，不再有 `Ctrl+↑`/`Ctrl+↓` 别名。文本输入由编辑器优先接收。
- Docker 的容器筛选和监控频率使用 `f`，Compose 启停使用 `t`，可信仓库和远端源新增使用 `a`；清理确认页用 `r a` 全选、`Enter` 执行。可信任远端源列表用 `dd` 删除当前仓库（凭据清理沿用原逻辑）。
- Docker「Systemd 代理配置」（docker.service drop-in）同样是公共参数表单：`↑↓/k/j` 移动字段，`Enter` 编辑或执行底部操作行；编辑态 `Enter` 保存字段、`Esc` 取消、`←→/Home/End` 移动光标、`Backspace/Delete` 删除；「查看原始文件」只读弹框用 `↑↓/PgUp/PgDn` 滚动、`Esc/q` 关闭；保存成功后进入「确认生效方式」页，`Enter/y` 执行 systemctl daemon-reload 并重启 Docker，`Esc/q/n` 稍后手动应用并回到表单；读取失败页用 `r` 重新读取。
- Docker「守护进程配置」（daemon.json）是公共参数表单：`↑↓/k/j` 移动字段，`Enter` 编辑文本/展开枚举下拉/执行底部操作行，`Space` 切换布尔开关；字段编辑态 `Enter` 保存字段、`Esc` 取消并保留原值、`←→/Home/End` 移动光标、`Backspace/Delete` 删除；枚举下拉用 `↑↓/PgUp/PgDn` 选择、`/` 搜索、`Enter` 确认、`Esc/q` 取消。底部「查看原始 JSON」只读弹框用 `↑↓/PgUp/PgDn` 滚动、`Esc/q` 关闭；保存成功后进入「确认生效方式」页，`Enter/y` 立即重启 Docker，`Esc/q/n` 稍后手动重启并回到表单；解析失败页用 `r` 重新读取。
- Docker 运行时参数记录编辑器用 `a` 新增记录、`dd` 删除当前记录，`Enter` 提交编辑；删除一行后待确认状态立即清空，紧接着的第三下 `d` 只重新登记下一行，必须再完成一次 `dd` 才会删除。
- Docker 上传镜像确认页用 `↑↓/k/j` 选择字段，`Space` 或焦点在“保留本地目标标签”开关上的 `Enter` 切换该选项，其余 `Enter` 与 `y` 确认上传，`Esc/q/n` 返回目标仓库列表。该选项默认否：上传成功后删除为本次上传添加的本地目标标签，选择是则保留在本机；目标标签与本地镜像同名或上传失败时始终保留。
- Docker 镜像选择页（导出选择镜像、上传选择镜像）的合并行（标签列显示「多个」）不套用「未勾选任何项时回车先勾选当前项」的通用多选约定：`Enter` 只提交已经勾选的镜像，合并行的标签必须用 `Space` 打开「选择标签」多选弹框显式勾选，弹框内用 `r a` 切换全选/取消全选（当前可见标签全部已勾选时清空全部勾选）。列表里 `r a` 对光标所在行一键全选/取消整行：合并行表示该镜像名的全部标签（清掉单独的标签勾选记录），已经挑过部分标签时也按整行全选处理，单标签行等同 `Space`。全选键统一为 `r a`，小写 `a` 只表示「新增」，不得再作为全选的等效键，未声明的小写字母不会改变勾选。单标签行保持 `Space` 勾选、`Enter` 先勾选当前行再确认。
- Docker 镜像列表（查看镜像列表、导出选择镜像、上传选择镜像）声明 `S` 排序；镜像详情弹框与「选择标签」弹框同样声明 `S` 排序标签，排序弹框覆盖在来源弹框之上，弹框打开时只声明弹框自己的 `Space/←→/Shift+↑↓/Enter/Esc/q` 和上下移动，来源页动作键不再生效。 镜像详情、容器概览预览和容器详情预览都由 `i` 打开：展示期间再按 `i` 关闭，帮助栏显示 `i 关闭…`。
- 只有「查看镜像列表」声明 `d` 删除镜像：连续两下 `d` 删除当前行，不再有单独确认页。第一次 `d` 只在信息展示区展示目标镜像、整行全部标签、是否仍被容器引用以及“删除后不可恢复”，帮助栏提示“再按一次删除镜像”；待确认状态会一直保留到下一次按键，其他按键、移动光标或再次切换页面都会取消。第二次 `d` 直接进入覆盖式执行视图逐个标签调用 daemon，成功与失败都保留明细；镜像仍被容器（含已停止容器）引用时 Docker 会拒绝删除，不做强制删除。导出选择镜像、上传选择镜像页不得声明 `d`。
- 镜像列表里组内取值不一致的“多个”行不参与列表排序、固定排在最后；打开镜像详情弹框或「选择标签」弹框时，标签顺序跟随镜像列表排序里能对应上的列（标签、镜像 ID、大小、使用中、创建时间，镜像名跳过）并显示同样的方向标记，在标签界面按 `S` 确认过自己的排序后以标签排序为准，把排序键全部移出再确认即恢复跟随。
- 筛选（`/` 确认后）与排序是正常组合：排序不得清掉筛选词，可见行仍是筛选结果、只是顺序按排序键。
- 列表页的 `←/→` 整页翻动由 Shell 统一翻译：模块实现 `shell.ListPageProvider` 的 `IsListPage()` 只在“当前是列表页、真的存在上一页/下一页、当前状态已声明 `PgUp/PgDn`”时返回 true；Shell 同时要求没有可见弹框、模块没有自己声明 `←/→`，命中时把 `←/→` 转成 `PgUp/PgDn` 交给模块，并在帮助栏追加 `←→ 翻页`。模块不得自行在内容区把 `←/→` 当翻页键，弹框列表仍用弹框自己的 `PgUp/PgDn` 翻页。
- 内容区焦点键：`←`/`→` 是内容区回到左侧主界面（模块选择）的焦点键，模块根页与二级子模块一致——模块没有自己声明 `←/→`、当前也不是多页列表时，`←/→` 把焦点交回左侧主界面，并在帮助栏显示 `←→ 返回导航栏`；`Tab`/`Shift+Tab` 不是返回入口，只有当前状态显式声明时才下发给模块。回到导航栏后 `Tab`、`Shift+Tab`、`←`、`→` 仍可回到内容区。鼠标左键单击左侧导航面板同样能把焦点交回主界面：第一下只返回并定位命中的模块行，第二下点击同一行才切换模块；滚轮不承担返回，内容区聚焦时忽略。
- 内容区按键逐级返回：模块声明了 `q` 时由模块返回上一级；未声明（含模块根页）时 Shell 把 `q` 当作返回导航栏（等同 `r q`），并在帮助栏显示 `q 返回导航栏`，任何内容状态都不允许 `q` 既不显示也不生效。
- Clean 扫描结果和执行视图用 `i` 查看待删明细、`l` 查看日志明细，完成页用 `d` 查看已清理明细；这三个明细弹框显示期间再按同一键关闭。保存模板用 `r s`。Clean 用户模板列表用 `dd` 删除当前模板，内置模板在第一次 `d` 时就提示“内置模板不可删除”，不进入待确认。Find 条件选择完成用 `r x`。
- 简单部署映射列表用 `dd` 删除当前映射：第一次 `d` 在信息展示区显示待删除映射与影响范围，第二次 `d` 才校验并保存配置，保存失败保留原列表；筛选词和光标按删除后的列表恢复。同一页面用 `r i` 导入映射、`r e` 导出空样例、`r d` 复制映射，`i` 从路径识别、`a` 新增、`Enter` 编辑；`r i` 与「打开生成物文件」的 `r o/r O` 互不替代。
- Database 备份计划列表用 `a` 新增；表单中的执行、导出与恢复由可见操作行的 `Enter` 触发。AIOps 服务器/项目管理弹框用 `a` 新增；部署提交仍走可见动作行及确认页。文件中转预检后继续使用现有 `F2` 或可见动作行，真正导出使用确认页的 `Enter`。
- 工具模块的随机密码结果页用 `c` 复制当前密码，不分平台隐藏：有本机剪贴板就写本机剪贴板，SSH 或无桌面会话改用终端 OSC 52，短反馈必须说明实际使用的通道；复制属于同步短操作，反馈期间任意键只关闭反馈。密码不得写入日志、审计字段或反馈文案。
- Docker 和 Database 已登记的生成物保留公共打开动作；文件中转成功导出后也登记目标文件或目录。没有生成物或没有可用图形会话时不显示打开键。
- Docker 文件复制页用 `m` 查看挂载和文件变化（`/` 保留为通用搜索键），该只读弹框显示期间再按 `m` 关闭。
- Docker 数据卷备份的完成页必须展示解析后的绝对备份目录、数据卷数量、成功/失败数量、文件清单和失败原因，并把备份目录登记为生成物：有备份文件时 `o` 打开目录、`r o/r O` 打开文件；容器没有命名卷或全部失败时仍登记备份目录，`o` 打开该目录确认空结果。默认输出目录仍是 `./backups`（按启动时工作目录解析为绝对路径），bind mount 不属于命名卷、不参与备份，完成页必须明确说明。

模块不得为没有对应功能的页面补业务流程，也不得把 `a/d/i` 声明成猜测式动作。新增或修改键位时，应同时更新帮助栏、门控、状态到动作测试和本规范。
