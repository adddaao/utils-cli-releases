# Docker 排障能力未完成清单

本轮已实现实时日志、容器筛选、结构化容器详情与统一资源入口，并完成以下排障闭环：

- 容器工作台按对象提供概览、实时日志、监控、文件、运行参数、备份、提交镜像和受控生命周期操作；删除默认不删除本地卷，且必须二次确认。
- 日志通过 Docker SDK 可取消流式读取，区分 stdout/stderr、支持 TTY、历史补拉、去重、断流重连与 3200 行内存上限；全程只在 TUI 中渲染。
- Compose 项目按标签聚合服务和副本，可从项目进入服务、再进入容器；项目和服务操作只作用于已发现容器，不依赖本机 Compose 文件。
- 资源浏览提供占用分析和一键清理预设。默认清理镜像、退出容器和未使用网络；本地卷必须显式勾选。

以下能力明确延期，避免以不完整实现破坏 TUI 边界。

## 内嵌交互 Shell

需要以暂停并恢复 Bubble Tea 的方式接管 TTY，同时处理 stdin/stdout、窗口尺寸、退出码和异常恢复。未完成前不在 TUI 中暴露入口。

## 原始 JSON Inspect

原始 JSON 属于结构化数据。本项目详情页应优先提供属性表格、挂载、网络和配置摘要；如果后续确有导出需求，应作为生成文件动作，而不是在内容区直接展示不可读的大段 JSON。
