# Find 命令可视化模块功能设计文档

## 1. 模块概述

### 1.1 功能定位

提供一个可视化的交互式界面，帮助用户通过图形化方式构建和执行 `find` 命令，无需记忆复杂的命令行参数。

### 1.2 目标用户

- 不熟悉 find 命令语法的用户
- 需要快速构建常用 find 查询的用户
- 希望通过可视化方式学习 find 命令的用户

### 1.3 核心特性

- ✅ 全中文界面展示所有参数
- ✅ 支持多条件组合（全选/部分选择）
- ✅ 提供常用查询模板（预设组合）
- ✅ 实时预览生成的命令
- ✅ 支持执行命令并查看结果
- ✅ 支持保存常用查询模板

## 2. 功能需求

### 2.1 主菜单集成

在主菜单中添加 "Find 文件查找" 选项，与其他模块（Docker、清理工具、防火墙）并列。

### 2.2 核心功能流程

#### 2.2.1 模式选择

用户进入 Find 模块后，首先选择使用模式：

1. **自定义构建** - 逐步选择参数构建命令
2. **模板选择** - 从预设模板中选择并执行
3. **历史记录** - 查看和执行历史命令

#### 2.2.2 自定义构建流程

1. 选择搜索路径（支持输入或选择常用路径）
2. 选择文件类型（文件/目录/链接等）
3. 选择过滤条件（可多选）：
   - 名称匹配
   - 大小过滤
   - 时间过滤
   - 权限过滤
   - 用户/组过滤
4. 选择执行动作（打印/删除/执行命令等）
5. 预览生成的命令
6. 确认执行或导出命令

#### 2.2.3 模板选择流程

1. 显示预设模板列表
2. 选择模板
3. 可编辑模板参数
4. 预览并执行

## 4. Find 命令参数中文映射表

### 4.1 基本参数

| 参数 | 中文名称 | 说明 | 示例 |
|------|---------|------|------|
| `path` | 搜索路径 | 起始搜索目录 | `.`, `/home`, `~/Documents` |
| `-name pattern` | 名称匹配 | 按文件名匹配（区分大小写） | `-name "*.log"` |
| `-iname pattern` | 名称匹配（忽略大小写） | 按文件名匹配（不区分大小写） | `-iname "*.LOG"` |
| `-regex pattern` | 正则表达式匹配 | 使用正则表达式匹配完整路径 | `-regex ".*\.(log\|txt)$"` |
| `-type type` | 文件类型 | 指定文件类型 | `-type f` (文件), `-type d` (目录) |

### 4.2 大小过滤

| 参数 | 中文名称 | 说明 | 示例 |
|------|---------|------|------|
| `-size n[cwbkMG]` | 大小过滤 | 按文件大小过滤 | `-size +100M` (大于100MB), `-size -10k` (小于10KB) |
| `-empty` | 空文件/目录 | 查找空文件或空目录 | `-empty` |

### 4.3 时间过滤

| 参数 | 中文名称 | 说明 | 示例 |
|------|---------|------|------|
| `-mtime n` | 修改时间 | 按修改时间过滤（天数） | `-mtime -7` (7天内), `-mtime +30` (30天前) |
| `-atime n` | 访问时间 | 按访问时间过滤（天数） | `-atime -1` (1天内访问) |
| `-ctime n` | 状态改变时间 | 按状态改变时间过滤（天数） | `-ctime -7` (7天内状态改变) |
| `-mmin n` | 修改时间（分钟） | 按修改时间过滤（分钟数） | `-mmin -60` (60分钟内) |
| `-newer file` | 比文件新 | 查找比指定文件新的文件 | `-newer reference.txt` |

### 4.4 权限过滤

| 参数 | 中文名称 | 说明 | 示例 |
|------|---------|------|------|
| `-perm mode` | 权限匹配 | 按权限模式匹配 | `-perm 644`, `-perm /u+x` (用户可执行) |
| `-readable` | 可读 | 查找当前用户可读的文件 | `-readable` |
| `-writable` | 可写 | 查找当前用户可写的文件 | `-writable` |
| `-executable` | 可执行 | 查找当前用户可执行的文件 | `-executable` |

### 4.5 用户/组过滤

| 参数 | 中文名称 | 说明 | 示例 |
|------|---------|------|------|
| `-user name` | 用户 | 按文件所有者过滤 | `-user root` |
| `-group name` | 组 | 按文件所属组过滤 | `-group www-data` |
| `-uid n` | 用户ID | 按用户ID过滤 | `-uid 1000` |
| `-gid n` | 组ID | 按组ID过滤 | `-gid 100` |

### 4.6 深度控制

| 参数 | 中文名称 | 说明 | 示例 |
|------|---------|------|------|
| `-maxdepth n` | 最大深度 | 限制搜索的最大目录深度 | `-maxdepth 3` |
| `-mindepth n` | 最小深度 | 限制搜索的最小目录深度 | `-mindepth 2` |

### 4.7 逻辑操作符

| 参数 | 中文名称 | 说明 | 示例 |
|------|---------|------|------|
| `-and` | 与 | 逻辑与（默认，可省略） | `-name "*.log" -size +100M` |
| `-or` | 或 | 逻辑或 | `-name "*.log" -or -name "*.txt"` |
| `-not` | 非 | 逻辑非 | `-not -name "*.tmp"` |
| `!` | 非（简写） | 逻辑非的简写形式 | `! -name "*.tmp"` |

### 4.8 执行动作

| 参数 | 中文名称 | 说明 | 示例 |
|------|---------|------|------|
| `-print` | 打印 | 打印文件路径（默认） | `-print` |
| `-print0` | 打印（空分隔） | 使用空字符分隔输出 | `-print0` |
| `-delete` | 删除 | 删除找到的文件 | `-delete` |
| `-exec command {} \;` | 执行命令 | 对每个文件执行命令 | `-exec trash {} \;` |
| `-exec command {} +` | 执行命令（批量） | 批量执行命令（更高效） | `-exec chmod 644 {} +` |
| `-ok command {} \;` | 执行命令（确认） | 执行前需要确认 | `-ok trash {} \;` |
| `-ls` | 列出详细信息 | 以 ls -dils 格式列出 | `-ls` |

## 5. 预设模板详细设计

### 5.1 模板列表

#### 模板 1: 查找大文件

```bash
find . -type f -size +100M -print
```

**参数说明:**

- 路径: 当前目录
- 类型: 文件
- 大小: 大于 100MB
- 动作: 打印

#### 模板 2: 查找最近修改的文件

```bash
find . -type f -mtime -7 -print
```

**参数说明:**

- 路径: 当前目录
- 类型: 文件
- 时间: 7天内修改
- 动作: 打印

#### 模板 3: 查找空文件

```bash
find . -type f -empty -print
```

**参数说明:**

- 路径: 当前目录
- 类型: 文件
- 条件: 空文件
- 动作: 打印

#### 模板 4: 查找临时文件

```bash
find . -type f \( -name "*.tmp" -o -name "*.temp" -o -name "*.swp" \) -print
```

**参数说明:**

- 路径: 当前目录
- 类型: 文件
- 名称: *.tmp 或*.temp 或 *.swp
- 动作: 打印

#### 模板 5: 查找可执行文件

```bash
find . -type f -executable -print
```

**参数说明:**

- 路径: 当前目录
- 类型: 文件
- 权限: 可执行
- 动作: 打印

#### 模板 6: 查找特定用户文件

```bash
find . -type f -user root -print
```

**参数说明:**

- 路径: 当前目录
- 类型: 文件
- 用户: root（可编辑）
- 动作: 打印

#### 模板 7: 查找重复文件（按大小）

```bash
find . -type f -exec ls -lh {} \; | awk '{print $5, $9}' | sort | uniq -d
```

**参数说明:**

- 路径: 当前目录
- 类型: 文件
- 动作: 按大小分组查找重复

#### 模板 8: 清理旧日志文件

```bash
find /var/log -type f -name "*.log" -mtime +30 -delete
```

**参数说明:**

- 路径: /var/log
- 类型: 文件
- 名称: *.log
- 时间: 30天前修改
- 动作: 删除

#### 模板 9: 查找特定扩展名文件

```bash
find . -type f \( -name "*.jpg" -o -name "*.png" -o -name "*.gif" \) -print
```

**参数说明:**

- 路径: 当前目录
- 类型: 文件
- 名称: 图片文件（jpg/png/gif）
- 动作: 打印

#### 模板 10: 查找并统计文件数量

```bash
find . -type f -name "*.log" | wc -l
```

**参数说明:**

- 路径: 当前目录
- 类型: 文件
- 名称: *.log
- 动作: 统计数量

## 7. 技术实现要点

### 7.1 模块结构

```
internal/
  find/
    cmd.go          # 命令行入口（可选）
    builder.go      # 命令构建器
    executor.go     # 命令执行器
    templates.go     # 模板管理
    history.go      # 历史记录管理
  tui/
    find.go         # Find TUI 模型
```

### 7.2 核心数据结构

```go
// FindQuery 表示一个 find 查询
type FindQuery struct {
    Path      string        // 搜索路径
    Type      string        // 文件类型 (f/d/l等)
    Conditions []Condition  // 过滤条件列表
    Action    Action        // 执行动作
}

// Condition 表示一个过滤条件
type Condition struct {
    Type    string  // 条件类型 (name/size/time/perm/user等)
    Operator string // 操作符 (eq/gt/lt/regex等)
    Value   string  // 条件值
}

// Action 表示执行动作
type Action struct {
    Type    string  // 动作类型 (print/delete/exec等)
    Command string  // 如果是 exec，这里是命令模板
}
```

### 7.3 命令生成逻辑

1. 从用户选择构建 `FindQuery` 结构
2. 根据条件类型和操作符生成对应的 find 参数
3. 处理逻辑操作符（AND/OR/NOT）
4. 生成最终的命令字符串
5. 验证命令语法（可选）

### 7.4 命令执行

1. 使用 `exec.Command` 执行生成的命令
2. 实时显示输出结果
3. 处理错误情况
4. 记录执行历史

### 7.5 模板管理

1. 内置模板存储在代码中
2. 用户自定义模板保存到配置文件
3. 支持模板的导入/导出
4. 模板参数可编辑

## 附录：Find 命令常用场景速查

### 场景 1: 查找并删除临时文件

```bash
find . -type f \( -name "*.tmp" -o -name "*.swp" \) -delete
```

### 场景 2: 查找大文件并排序

```bash
find . -type f -size +100M -exec ls -lh {} \; | sort -k5 -h
```

### 场景 3: 查找最近 7 天修改的文件

```bash
find . -type f -mtime -7 -print
```

### 场景 4: 查找空目录

```bash
find . -type d -empty -print
```

### 场景 5: 查找特定权限的文件

```bash
find . -type f -perm 777 -print
```

### 场景 6: 查找并压缩日志文件

```bash
find /var/log -name "*.log" -mtime +30 -exec gzip {} \;
```

### 场景 7: 查找并统计文件类型

```bash
find . -type f -name "*.jpg" | wc -l
```

### 场景 8: 查找重复文件（按内容）

```bash
find . -type f -exec md5sum {} \; | sort | uniq -d -w 32
```
