# 清理模块配置重构计划 (移除 Maven 旧配置)

## 目标
完全移除 `AppConfig` 中的 `Maven` 字段，不再兼容旧配置。将 Maven 规则作为 `Clean.CustomRules` 的一种特殊形式或保留内置逻辑但使用新配置结构。
鉴于 Maven 规则有特殊的“隐藏文件清理”逻辑（`._*`），保留其作为内置规则代码实现，但配置参数应迁移到统一的 `[clean]` 结构中，或者为 Maven 保留专有的 `[clean.maven]` 配置段。

为了保持配置的统一性与灵活性，建议方案：
1.  **移除 `[maven]` 顶层配置**：删除 `Maven` 结构体。
2.  **新增 `[clean]` 配置**：
    *   `[clean.maven]`：专用于 Maven 规则的配置（路径、后缀），保留其特殊逻辑。
    *   `[[clean.custom_rules]]`：通用自定义规则列表。
3.  **更新默认配置**：`defaultToml` 生成新的 TOML 结构。
4.  **代码适配**：更新 `MavenRule` 读取 `config.Clean.Maven` 而非 `config.Maven`。

## 变更详情

### 1. `internal/config/config.go`
- **删除** `Maven` 结构体定义。
- **更新** `Clean` 结构体：
```go
type Clean struct {
    Maven struct {
        TargetSuffixes []string `mapstructure:"suffixes"`
        DefaultPaths   []string `mapstructure:"paths"`
    } `mapstructure:"maven"`

    CustomRules []struct {
        Name     string   `mapstructure:"name"`
        Paths    []string `mapstructure:"paths"`
        Suffixes []string `mapstructure:"suffixes"`
        Enabled  bool     `mapstructure:"enabled"`
    } `mapstructure:"custom_rules"`
} `mapstructure:"clean"`
```
- **更新** `Load` / `SetDefault`：
    *   删除 `v.SetDefault("maven.suffixes", ...)`
    *   新增 `v.SetDefault("clean.maven.suffixes", ...)`
- **更新** `defaultToml()`：
    *   移除 `[maven]` 块。
    *   添加 `[clean.maven]` 块与示例。

### 2. `internal/clean/maven.go`
- **更新** `Execute` 方法：
    *   读取 `cfg.Clean.Maven.TargetSuffixes`
    *   读取 `cfg.Clean.Maven.DefaultPaths`

### 3. 文档与迁移
- 提示用户手动迁移或接受默认值（因不要求兼容旧配置，旧配置将失效）。

## 执行步骤
1.  修改 `config.go`：重构结构体与默认值。
2.  修改 `maven.go`：适配新配置路径。
3.  验证构建与运行。
