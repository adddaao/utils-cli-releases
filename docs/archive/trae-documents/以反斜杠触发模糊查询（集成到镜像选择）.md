## 目标

* 在交互选择镜像时，支持以 \ 开头触发模糊查询模式

* 保持当前展示全部镜像→输入序号/区间的流程不变

## 行为

* 提示更新为：输入序号/区间（例如 0,2,5-8），或输入 “\关键词” 进行模糊查询

* 模糊查询支持：关键词/首字母/拼音首字母，500ms 限时返回

* 查询结果以编号展示，随后再次输入序号/区间进行选择

* 错误输入（格式/越界）提供明确原因与示例，允许重试

## 改动

* 修改 `internal/ui/select.go` 的 `SelectImages`：

  * 引入 `internal/fuzzy` 与 `internal/config`

  * 在读取输入时分支：普通索引解析或以 \ 触发模糊查询

  * 打印候选并二次选择，返回所选镜像

## 验证

* 构建后运行 `./dit save -i`

* 在镜像选择步骤输入：`\nginx`、`\n a`（首字母）、或映射的拼音首字母，观察 Top10 输出与二次选择

* 输入非法序号与越界区间，得到错误提示与重试
