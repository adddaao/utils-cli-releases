## 目标

* 在调试模式首次启动时初始化 `./.Rutils/config.toml`（权限 600，UTF-8）并写入默认配置。

* 运行时实现分层加载：默认值 → 配置文件 → 环境变量。

* 提供类型校验、路径规范化、热更新（可选）、调试日志、配置版本与迁移能力。

## 主要改动

* `internal/config/config.go`：新增调试模式路径、首次初始化写入、权限设置、分层加载、`validate_config()`、`config_version`、热更新与日志。

* `cmd/dit/main.go`：添加全局 `--debug` 与 `RUTIL_DEBUG` 环境变量支持，在 `PersistentPreRunE` 中调用配置加载。

* `docs/configuration.md`：新增示例与说明（TOML 模板）。

## 路径策略

* 调试模式：默认使用相对项目根的 `./.Rutils/config.toml`。

* 非调试模式：默认使用用户目录 `~/.Rutils/config.toml`。

* 明确支持 `--config` 指定文件，优先级最高。

## 分层加载与校验

* 默认值（硬编码）：

  * `input_path = "./images/"`

  * `output_path = "./images/"`

  * `search_keywords = ['\']`

  * `log_level = "debug"`, `max_retries = 3`, `timeout = 30`, `config_version = 1`

* 覆盖顺序：默认 → 配置文件 → 环境变量（前缀 `RUTIL_`）。

* `validate_config()`：

  * 类型校验（字符串/数组/整数/正数）。

  * 路径规范化：相对路径转绝对路径（保留原相对语义），清理尾部斜杠。

  * `input_path` 必须存在；`output_path` 不存在则自动创建。

  * `log_level` 仅允许 `debug|info|warn|error`。

## 首次初始化

* 判断配置文件是否存在；不存在则：

  * 创建 `.Rutils/` 目录（相对或 `~` 目录）。

  * 生成 `config.toml`（UTF-8）；写入默认配置与注释。

  * 设置文件权限 `0600`（Unix）；Windows 跳过权限位但依旧写入。

## 热更新（可选）

* 使用 `viper.WatchConfig()` + `OnConfigChange(...)`。

* 变更时重新反序列化与 `validate_config()`；记录调试日志。

## 调试日志

* 当 `log_level=debug` 或启用 `--debug`/`RUTIL_DEBUG`：

  * `[DEBUG] Loaded config from <路径>`

  * `[DEBUG] Effective: input_path=..., output_path=..., ...`

  * `[DEBUG] Using default for <键>` 提示缺失项的默认值。

## 文档

* 新增 `docs/configuration.md`，包含：

  * TOML 模板（示例与中文注释）。

  * 层级覆盖说明与调试/非调试路径策略。

  * 热更新与环境变量前缀 `RUTIL_`。

## 迁移

* 新增 `config_version` 字段与 `config migrate` 子命令（占位实现）：

  * 从旧版本键名/路径迁移到当前版本；必要时备份旧文件。

## 验证

* `make run` 加 `--debug` 首次运行：自动生成 `./.Rutils/config.toml` 并加载，输出调试日志。

* 非调试模式：生成并使用 `~/.Rutils/config.toml`。

* 修改配置文件：触发热更新并重新校验。
