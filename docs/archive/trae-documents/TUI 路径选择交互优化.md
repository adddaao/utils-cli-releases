# 改进路径选择模块交互体验

为了实现“支持手动输入和默认选择，且可自由切换”的需求，将引入**焦点切换（Focus Switching）**机制。

## 1. 状态模型升级 (`internal/tui/clean.go`)

*   **新增焦点状态定义**：
    ```go
    const (
        pathFocusList  = 0 // 焦点在列表
        pathFocusInput = 1 // 焦点在输入框
    )
    ```
*   **修改 `CleanModel`**：添加 `pathFocus int` 字段用于跟踪当前焦点。

## 2. 交互逻辑优化 (`Update` 方法)

在 `cleanStatePathSelect` 状态下：

*   **Tab / Shift+Tab**：在“输入框”和“列表”之间循环切换焦点。
    *   切换到**列表**时：`m.input.Blur()`，列表组件激活。
    *   切换到**输入框**时：`m.input.Focus()`，列表组件暂停响应。

*   **Enter 键**：
    *   **焦点在列表**：确认使用当前列表选中的路径。
    *   **焦点在输入框**：确认使用输入框中的文本路径。

*   **Esc 键**：保持原有逻辑（返回上一级）。

## 3. 视觉反馈增强 (`View` 方法)

*   **动态样式**：
    *   **输入框**：获得焦点时显示高亮边框/提示色；失去焦点时变暗。
    *   **列表**：获得焦点时正常显示选中行；失去焦点时隐藏选中行高亮或整体变暗，明确告知用户当前列表不可操作。

## 4. 预期效果

用户进入路径选择界面后：
1.  默认焦点在**列表**，可直接上下选择常用路径。
2.  如需自定义，按 **Tab** 切换到输入框，输入路径。
3.  如果输入一半改变主意，再次按 **Tab** 切回列表，直接选择默认路径（无需清空输入框）。
