# 完善 Maven 清理与新增清理分组功能

本计划旨在实现 Maven 清理的完整流程（含预览与日志），并新增 macOS、压缩包、临时文件等默认清理分组。

## 1. 配置结构更新 (`internal/config/config.go`)
更新 `Clean` 配置结构，支持新的分组与特性：
- **Maven**: 新增 `preview_delete` (bool) 开关。
- **MacOS**: 新增 `macos` 分组，包含 `enabled`, `paths`。
- **Archive**: 新增 `archive` 分组，包含 `enabled`, `paths`, `suffixes`, `clean_unzip`。
- **Temp**: 新增 `temp` 分组，包含 `enabled`, `paths`, `suffixes`, `retention` (如 "24h")。
- 更新 `defaultToml` 以包含上述默认配置。

## 2. 日志模块实现 (`internal/logger`)
由于目前项目中虽有日志配置但无实现，将创建一个轻量级日志模块：
- **功能**: 支持输出到文件（路径由配置指定），格式包含时间戳、级别、信息。
- **集成**: 在 `main.go` 启动时初始化，并在清理操作中调用以记录详细删除日志。

## 3. 清理规则实现 (`internal/clean/`)
### 3.1 Maven 规则增强 (`maven.go`)
- **流程优化**: 
    - 读取配置中的 `paths` (默认 `~/.m2/repository`)。
    - 检查 `preview_delete` 配置。如果启用且非 CLI 模拟模式，先执行扫描展示列表，经用户确认后再执行删除。
- **日志记录**: 记录每个删除文件的路径、大小、修改时间。

### 3.2 新增 macOS 规则 (`macos.go`)
- **目标**: `.DS_Store`, `._*` 文件。
- **安全机制**: 
    - 强制排除 `/System`, `/Library`, `/usr` 等系统关键目录。
    - 用户主目录扫描时的安全检查。

### 3.3 新增压缩包规则 (`archive.go`)
- **目标**: `.zip`, `.tar`, `.gz`, `.7z` 等。
- **特性**: 
    - **文件锁定检测**: 在删除前尝试以独占模式打开文件，若失败（被占用）则跳过。
    - **解压目录清理**: (可选) 根据配置清理对应的解压目录。

### 3.4 新增临时文件规则 (`temp.go`)
- **目标**: `.tmp`, `.temp`, `~` 开头文件。
- **特性**: 
    - **过期检查**: 根据 `retention` 配置（默认 24h），仅删除修改时间超过阈值的文件。

## 4. CLI 交互与展示 (`internal/clean/cmd.go`, `internal/ui`)
- **注册新规则**: 将上述新规则注册到清理管理器。
- **展示优化**: 
    - 在执行前显示将要删除的文件统计信息（数量、大小）。
    - 预览模式下展示详细文件列表。

## 5. 验证计划
- **单元测试**: 对路径排除逻辑、过期时间判断逻辑进行测试。
- **模拟运行**: 使用 `dry-run` 模式验证各分组的匹配情况，确保不误删系统文件。
