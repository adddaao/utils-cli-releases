# 添加快捷键提示并实现帮助文本自动换行

## 1. 修改 `internal/tui/util.go`

添加 `BuildWrappedHelp` 和 `WrapHelpText` 函数，用于根据屏幕宽度自动换行帮助文本。这将确保在窗口较小时，帮助信息不会被截断，而是优雅地换行显示。

*   **引入依赖**: 添加 `strings` 和 `github.com/charmbracelet/lipgloss`。
*   **新增函数**:
    *   `WrapHelpText(width int, parts []string) string`: 核心换行逻辑，使用 `lipgloss.Width` 计算实际显示宽度。
    *   `BuildWrappedHelp(width int, parts ...string) string`: 统一封装，自动添加标准前缀（如 "↑↓ 移动" 等），保持与现有 `BuildHelpLine` 风格一致但支持换行。

## 2. 修改 `internal/tui/find.go`

在 `View` 方法中，针对 `findStateConditionEditor`（条件编辑器）状态：

*   **更新帮助文本**: 将原来的 `BuildHelpLine` 调用替换为 `BuildWrappedHelp`。
*   **添加快捷键**: 在帮助列表中加入 `"Ctrl+M/m 移动"`，提示用户可以使用新功能。
*   **传递宽度**: 将 `m.width` 传递给 `BuildWrappedHelp` 以启用自动换行。

此变更将统一解决用户提出的两个需求：显示新增快捷键提示以及统一的换行处理方法。
