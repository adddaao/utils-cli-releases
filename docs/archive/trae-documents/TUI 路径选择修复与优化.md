# TUI 路径选择模块修复与优化计划

针对用户反馈的样式异常和功能问题，进行以下核心修复：

## 1. 修复样式异常 (Critical)

*   **移除 View 中的副作用**：目前在 `View()` 方法中调用 `m.list.SetHeight()` 是错误的，这会导致渲染状态不稳定。将列表高度的计算和设置移至 `Update()` 的 `tea.WindowSizeMsg` 处理逻辑中。
*   **动态高度计算**：根据窗口实际高度，减去输入框、标题、边框等占用的空间，动态计算列表的剩余可用高度，避免溢出或留白过多。
*   **边框优化**：调整 `lipgloss` 样式，确保输入框和列表的边框在不同尺寸终端下显示协调，避免“大框”视觉割裂。

## 2. 完善手动输入功能

*   **焦点管理**：确保 Tab 切换时，`textinput` 的 `Focus()` 和 `Blur()` 被正确调用，使光标的显隐状态符合用户预期。
*   **空输入处理**：当用户在输入框按 Enter 但内容为空时，提供反馈或回退逻辑（如默认选中列表第一项），避免“点击无反应”的现象。
*   **输入提示优化**：当焦点在列表时，输入框显示更友好的提示文本（如“按 Tab 键手动输入路径”）。

## 3. 代码重构

*   **CleanModel.Update**: 集中处理窗口大小调整逻辑。
*   **CleanModel.View**: 保持纯粹的渲染逻辑，根据状态（`pathFocus`）渲染不同样式的组件。

## 验证计划

1.  运行 `dit clean`，调整终端窗口大小，确认列表高度自适应。
2.  在路径选择界面按 Tab 键，确认光标和边框高亮正确切换。
3.  输入路径后按 Enter，确认能正确进入下一步。
4.  清空输入框按 Enter，确认程序行为符合预期（如不执行或提示）。
