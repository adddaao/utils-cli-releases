# 主菜单数字序号重构验证计划

## 1. 目标与背景
主菜单已经成功使用 `UnifiedPageModel` 和 `numberSelectionBuffer` 进行了重构，支持了连续的数字序号和数字缓冲输入方式，并修复了相关测试用例。当前需要进行最后的运行验证和确认。

## 4. 验证步骤
1. 请用户在终端中运行应用程序 (`go run main.go`)。
2. 验证主菜单是否显示为数字序号（1, 2, 3, 4...）。
3. 验证通过方向键选择并按 Enter 是否正常进入右侧子菜单。
4. 验证输入数字（如 `2`），观察底部帮助栏是否出现缓冲提示，按 Enter 是否正常执行对应菜单项。
