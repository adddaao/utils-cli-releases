# 明确打印规则默认路径

针对用户反馈的 "不要模糊不清，直接打印出所对应的规则路径" 需求，制定以下修复计划。

## 1. 问题分析 (`internal/clean/cmd.go`)
- **现状**: 当前代码在 `pathInput` 为空时，仅简单提示 "使用各规则默认配置"，这对用户来说不直观，不知道实际会扫描哪里。
- **需求**:
  - 如果用户输入了路径，打印该路径。
  - 如果用户未输入（使用默认），需要解析并打印出每个选中规则的实际默认路径。
  - 对于 "当前目录"，打印绝对路径而不是 `.`。

## 2. 解决方案
- **扩展 `Rule` 接口**：增加 `DefaultPaths() []string` 方法，允许外部获取规则的默认扫描路径。
- **实现 `DefaultPaths`**：
  - `MavenRule`: 返回配置中的 Maven 路径或默认 `.m2/repository` (需 expand)。
  - `MacOSRule`: 返回配置中的 Paths 或用户主目录。
  - `ArchiveRule`, `TempRule`, `GenericRule`: 返回配置中的 Paths。
- **更新 `cmd.go` 逻辑**：
  - 遍历选中的 `selectedIDs`。
  - 如果 `scanPaths` 不为空（用户指定了覆盖路径），打印该路径。
  - 如果 `scanPaths` 为空（使用默认），对每个选中规则调用 `DefaultPaths()` 并打印。

## 3. 实施步骤

1. **修改接口 (`internal/clean/interface.go`)**:
   - 在 `Rule` 接口中添加 `DefaultPaths() []string`。

2. **实现接口方法**:
   - 更新 `internal/clean/maven.go`
   - 更新 `internal/clean/macos.go`
   - 更新 `internal/clean/archive.go`
   - 更新 `internal/clean/temp.go`
   - 更新 `internal/clean/generic.go`
   - 逻辑与各自 `Execute` 中的路径获取逻辑保持一致。

3. **修改 `cmd.go`**:
   - 在提示路径部分，如果 `scanPaths` 为空，遍历选中的规则，调用 `DefaultPaths`，并打印 "规则 [Name] 默认路径: [Paths]"。

## 4. 影响范围
- 需要修改所有 Rule 的实现。
- `cmd.go` 的输出逻辑。
- `tui` 模块可能也需要相应更新以展示明确路径（虽然用户主要指的是 `cmd.go` 中的输出，但 TUI 最好也保持一致）。

## 5. 特别注意
- `expandPaths` 函数目前是私有的（在 `maven.go` 中定义？需检查）。如果其他文件也需要用，可能需要提取到 `util` 或公开。
- 经检查 `maven.go` 中有 `expandPaths`，`generic.go` 中也有（可能是重复代码或同一个包下可见）。如果在同一个包 `clean` 下，`expandPaths` 是可见的。
