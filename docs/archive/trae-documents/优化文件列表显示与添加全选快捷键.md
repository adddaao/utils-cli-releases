# 修改 Docker 导入列表显示及添加全选功能

## 1. 修改 `dockerItem` 的显示逻辑

用户希望在选择归档文件时，不显示文件路径，只显示文件名称。

* **修改位置**: `internal/tui/docker.go` 中的 `archiveListMsg` 处理逻辑。

* **修改内容**: 在构造 `dockerItem` 时，将 `desc` 字段设置为空字符串（或者不包含路径信息），仅在 `path` 字段中保留原始路径用于后续逻辑。

* **注意**: 需要检查 `dockerItemDelegate.Render` 方法，确保它不再打印描述（如果描述为空，代码中已经有判断，所以只需修改数据源）。

## 2. 实现全选功能 (Ctrl+A)

用户希望在导入选择列表页面使用 `Ctrl+A` 进行全选。

* **修改位置**: `internal/tui/docker.go` 中的 `Update` 方法。

* **修改逻辑**:

  * 在 `case tea.KeyMsg` 中添加对 `ctrl+a` 的处理。

  * 检查当前状态是否为 `dockerStateLoadSelectArchives` (用户明确提到"目前只在这个页面")。

  * **全选逻辑**:

    * 遍历 `m.imageList.Items()`。

    * 将所有项的 ID 添加到 `m.selectedIDs` 映射中。

    * 更新所有列表项的 `selected` 状态为 `true`。

    * 调用 `m.imageList.SetItems(newItems)` 更新列表。

## 3. 验证计划

* **验证显示**: 进入导入页面，扫描归档文件，列表应仅显示文件名，不再有括号内的长路径。

* **验证全选**: 按下 `Ctrl+A`，所有列表项应变为选中状态 `[x]`。

* **验证后续流程**: 选中后按 Enter，应能正常进行后续导入操作。
