## 目标
- 所有输入点增加校验与友好错误提示，支持重试
- 保存功能内置模糊查询：关键词/首字母/拼音首字母，500ms 内返回并给出备选

## 变更点
- 新增 `internal/validate/`：通用校验与重试输入
- 新增 `internal/fuzzy/`：索引与匹配、评分与 TopK
- 修改 `cmd/dit/main.go`：`save` 增加 `--query` 与交互入口集成模糊匹配
- 复用 `internal/ui/`：统一调用校验与提示

## 校验机制
- `validate/indices.go`：`ParseIndexList(text, max)` → 详细错误（格式、越界、区间非法），`SuggestIndexFormat()`
- `validate/int.go`：`ParseIntRange(text, min, max)` → 建议区间/默认值提示
- `validate/path.go`：`CheckPath(text, dirOnly)` → 不存在/类型错误/无权限，给出修正建议
- `ui/retry.go`：`PromptRetry(message, def, validator)` 通用重试包装，错误时打印原因与建议并再次输入
- 应用位置：`wizard`、`list -i`、`save -i`、`load -i` 全部改用 `PromptRetry`

## 模糊查询与匹配
- 索引构建：`fuzzy.Index` 从 `docker.Image` 生成条目：
  - `primary`：`repo:tag`
  - `tokens`：按 `[-/_:.]` 分词
  - `acronym`：各 token 首字母
  - `pinyin`：从配置 `config.Fuzzy.PinyinMap` 生成（可选），无则跳过
- 查询：`fuzzy.Query(index, q, topK, timeout)` 返回 `[]Result{image, score}`
  - 评分：
    - 子串命中：+3（位置越前加权）
    - 前缀命中：+4
    - 首字母命中：+5
    - 拼音首字母命中：+5
    - 词数覆盖：+1/词
  - 500ms 限时：超时降级为子串命中
- 展示：Top10 备选（含匹配理由/置信分），允许多选确认

## CLI 集成
- `save` 增加 `--query`；交互模式：
  - 未给 `--all/--filter` 时提示输入关键词→执行 `fuzzy.Query`→展示备选→多选确认
  - 选择后继续压缩类型/输出目录/并发度/覆盖确认（沿用现有 UI）
- 非交互：给 `--query` 时直接用模糊结果作为候选；无结果提示“无匹配”与建议改写

## 性能
- 索引 O(n)，查询 O(n)，单次线性扫描；`topK` 使用小根堆维持前10，确保 <500ms（千级镜像）
- 预热：首次调用保存时缓存索引于进程内（简单切片）；关键词变化重新查询

## 验证
- 构建运行：`go build -o dit ./cmd/dit`
- 交互：`./dit save -i` 输入多种非法与合法案例，观察错误与建议可用
- 模糊：`./dit save -i` 测试关键词/首字母/拼音映射，确认 Top10 与选择流程
- 限时：大量镜像下测响应时间，确保 <500ms；超时观察降级策略
