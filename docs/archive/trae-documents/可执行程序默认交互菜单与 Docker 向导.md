## 目标
- 无选项运行直接进入交互菜单（分类展示）
- 选择 Docker 后提供 Load/Save 向导，流程与示例保持一致
- 保存支持模糊查询（关键词/首字母/拼音首字母）、多选与区间输入、压缩与输出路径配置

## 行为改动
- 根命令增加 `RunE`：当无子命令时显示分类菜单（Docker/更多模块预留）
- 进入 Docker 分类后：先选择 `s`(save)/`l`(load)

## Save 流程
- 列出全部镜像并编号
- 输入关键词进行模糊查询（500ms Top10），展示候选可多选确认
- 索引输入支持：单个、逗号分隔、区间 `a-b`，错误给出格式/范围提示并重试
- 询问是否使用多线程及并发度（默认配置）
- 询问是否压缩与压缩类型（none/gzip/zstd/7z）
- 输出路径（默认 `./images`，不存在则创建）

## Load 流程
- 输入目录（默认 `./images`）
- 自动解压目录下 `.7z` 文件
- 列出 `.tar/.tar.gz` 并编号，多选与区间输入，错误提示并重试
- 并发度设置；完成后询问是否删除 `.tar`

## 复用与实现
- 复用现有 `internal/ui` 校验与重试、`internal/fuzzy` 索引与查询、`internal/transfer` 加载与 7z 解压
- `cmd/dit/main.go`：
  - 根命令 `RunE`：无参数时调起分类菜单与 Docker 向导
  - 保留现有子命令（list/save/load/verify/wizard）不变

## 验证
- 构建后直接运行 `./dit`：出现菜单→Docker→s/l 全流程
- 检查模糊查询响应（≤500ms）、错误提示与重试、默认路径 `./images` 生效
