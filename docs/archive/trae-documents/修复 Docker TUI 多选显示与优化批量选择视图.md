# 修复 Docker 管理 TUI 的多选显示和批量选择视图

## 1. 在默认试图下修改为单选模式 

在默认视图下只能使用单选进行选择 多选使用 tab切换为多选

## 2. 改进批量选择模式 (Batch Mode) 的视图

用户在批量选择模式下需要参考列表中的序号，因此必须同时显示列表和输入框。

* **状态切换处理 (`Update`)**:

  * 当进入批量选择模式 (`Tab` 键) 时，减少 `imageList` 的高度（例如减少 4-5 行），为底部的输入框腾出空间。

  * 当退出批量选择模式 (`Esc` 或 `Enter`) 时，恢复 `imageList` 的高度为全屏。

  * 在 `WindowSizeMsg` 处理中，根据当前状态动态计算列表高度。

* **视图渲染 (`View`)**:

  * 修改 `case dockerStateSaveBatchSelect, dockerStateLoadBatchSelect` 的渲染逻辑。

  * 组合渲染 `m.imageList.View()` 和 `m.input.View()`，使列表显示在上方，输入框显示在下方。

## 3. 验证

* 验证在默认选择模式下，按空格键选中条目时，是否出现 `[x]` 标记。

* 验证按 `Tab` 切换到批量模式后，列表是否依然可见，且底部出现输入框。

* 验证输入范围（如 `1-3`）并确认后，对应的条目是否被正确选中（显示 `[x]`）。
