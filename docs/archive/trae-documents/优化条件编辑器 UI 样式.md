我将优化 `ConditionEditor` 的视觉样式和交互体验，使其更接近 Navicat 的条件组合编辑器风格。

**优化方案**：

1. **重构表格样式**：

   * 移除 `headerStyle` 的背景色，改为简洁的粗体+前景。

   * `selectedCellStyle` 调整为更柔和的高亮色，避免过于刺眼。

   * `cellStyle` 增加内边距，使内容不拥挤。

   * 为表格添加外边框，增强整体感。

2. **优化选中行/单元格的视觉反馈**：

   * 使用不同的颜色或样式区分“当前行”和“当前焦点单元格”。

   * 当处于编辑模式时，输入框样式应与表格风格融合。

3. **改进空状态显示**：

   * 优化“没有条件”时的提示文案和样式，使其更居中且易于理解。

4. **优化工具栏**：

   * 调整按钮样式，使其看起来更像可点击的操作项。

   * 增加快捷键提示（如 `[Space] 添加`，`[Del] 删除`）。

5. **调整列宽逻辑**：

   * 根据窗口宽度动态调整列宽，特别是“值”列，充分利用屏幕空间。

**文件修改**：

* `internal/tui/finder_condition.go`: 修改样式定义、`renderHeader`、`renderRow`、`renderToolbar` 等方法。
