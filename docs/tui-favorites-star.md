# TUI 标星（关注）功能

> 正式文档入口：[docs/README.md](README.md)。本文描述左侧导航「标星/关注」的完整契约，新增模块接标星能力时必须先读本文。

## 1. 功能目标

把用户常用的入口集中到左侧导航顶部的固定分组「★ 我的关注」，并在**两级粒度**上支持标星：

| 级别 | 标星对象 | 目标 ID 形状 | 示例 |
| --- | --- | --- | --- |
| 模块级 | 左侧导航中的模块入口 | `<module_id>` | `docker` |
| 子功能级 | 内容区列表光标所在的功能项 | `<module_id>/<function_id>` | `docker/container_workbench`、`docker/export` |

子功能级覆盖**模块主菜单分组**和**各功能菜单里的功能项**（例如「镜像管理 → 导出镜像」）。镜像、容器、归档、仓库这类动态列表行不是稳定入口；执行态、编辑态、结果页、筛选输入态和弹框期间 `s` 交回来源页，不纳入标星范围。

## 2. 交互契约

### 2.1 关注分组

- 只要存在至少一个仍然有效的标星目标，导航列表顶部就渲染不可选中的分组标题 `★ 我的关注`，随后是关注项，再渲染 `全部功能` 分组标题与完整模块列表。
- 没有任何有效标星目标时不渲染分组标题，导航与旧版完全一致（不产生空分组噪声）。
- 光标移动（`↑↓/k j`、滚轮、鼠标点击）必须跳过分组标题；分组标题不可按 `Enter` 确认。
- 关注分组中的模块入口与「全部功能」中的同一模块同时存在；`s` 取消关注后光标回到「全部功能」中的该模块，不会跳到列表顶部。
- 面包屑使用模块名，不带关注前缀。

### 2.2 数字编号

- 模块编号（`1`..`7`）始终绑定**声明编号**，与「全部功能」分组中的模块一一对应，不随关注分组插入而漂移。
- 关注分组项不占用数字编号，只能用光标选择。实现方式是导航层把列表组件的"第 N 项"定位替换为"声明编号为 N 的模块项"（`selectNumberedItem`）。
- 数字键仍然只定位，必须再按 `Enter` 才执行。

### 2.3 `s` 键

| 焦点 | 条件 | 行为 |
| --- | --- | --- |
| 导航栏 | 当前项可标星且不在列表筛选态 | 切换该目标的关注状态 |
| 内容区 | 光标停在模块声明的可关注功能项上（主菜单分组或功能菜单项），模块自己未声明 `s`，且不在筛选输入态/弹框中 | 切换该功能项的关注状态 |

- 列表筛选态下 `s` 属于筛选文本，绝不触发标星。
- 弹框、编辑器、执行态等状态由 `CurrentStarFunction()` 返回空字符串来屏蔽，Shell 不接管 `s`。
- 标星结果通过右下信息展示区的一条短消息展示（`已关注：xxx` / `已取消关注：xxx`）：消息优先于模块信息显示，任意键先关闭消息并继续按原状态机生效，5 秒后自动关闭；不再覆盖主窗口，也不写入导航栏。
- 有可标星目标时帮助栏出现 `s 关注/取消关注`；不可标星时帮助栏不出现该条目。

## 3. 存储契约

- 文件：`<data_dir>/favorites.json`（`data_dir` 见 `config.GetDataDir()`）。
- 格式：

```json
{
  "version": 1,
  "targets": ["docker", "docker/container_workbench", "clean"]
}
```

- 权限：目录 `0700`，文件 `0600`；写入走同目录 `.pending.<uuid>` 临时文件 + 原子 `rename`，提交失败时把临时文件移入废纸篓，不留半成品。
- `targets` 保持用户标星顺序；读取时丢弃非法 ID、空 ID 与重复项，不报错。
- 文件不存在等价于"没有关注"，不视为错误；文件损坏时读取返回错误，导航降级为"没有关注"并继续可用。
- ID 只允许 `^[a-z0-9_]+(/[a-z0-9_]+)?$`，单文件最多 200 条。
- 模块下线或平台不支持时，失效目标继续保留在文件里但不出现在导航中；模块重新可用后会恢复显示。
- 该文件属于本地 UI 偏好，不写入 `config.toml`，因此不受配置版本迁移影响。

## 4. 模块接入契约

Shell 定义在 `internal/tui/shell/star_target.go`：

```go
type StarFunction struct {
	ID    string // 模块内稳定 ID，不含斜杠
	Label string // 导航显示短标签
}

type StarTargetProvider interface {
	StarFunctions() []StarFunction        // 当前平台真实可关注的功能项目录
	CurrentStarFunction() string          // 返回光标所在功能项 ID；不可关注时返回 ""
	NavigateStarFunction(functionID string) tea.Cmd // 从任意状态进入该功能项
}
```

接入要求：

1. 模块结构体实现三个方法（模块已 import `internal/tui/shell`，无需新增依赖）。参考实现：`internal/tui/modules/docker/docker_star.go`。
2. `StarFunctions()` 必须与当前平台真实渲染出的功能项一致（主菜单分组与功能菜单项，标签与菜单标题一致），不能硬编码其它平台才存在的项；被平台门控隐藏的项不得返回。
3. `CurrentStarFunction()` 是 `s` 键的唯一安全闸门：只有当前页面确实是功能菜单（模块需维护允许标星的菜单状态）、光标停在目录内的功能项上时才返回该项 ID；弹框、筛选输入、详情、执行、编辑、结果页一律返回 `""`。镜像、容器、归档、仓库等动态列表行因为不在目录内会自然返回 `""`。
4. `NavigateStarFunction()` 必须能在任意状态生效：先清掉会拦住"回到主菜单"的状态字段，再按功能项所属菜单分发（分组菜单项要先进入所属功能菜单并设置返回目标，保证 `Esc/q` 回到该分组）；未知或被门控隐藏的 id 返回 `nil`。
5. 模块自己声明了 `s` 按键时，模块优先，Shell 不接管。
6. 未实现该接口的模块仍然可以在**模块级**被标星，只是没有子功能级目标。

## 5. 失败与边界

| 场景 | 行为 |
| --- | --- |
| 偏好文件不存在 | 视为无关注，静默继续 |
| 偏好文件损坏 | 读取报错，导航按无关注渲染 |
| 偏好文件不可写 | 信息展示区消息提示 `标星失败：<原因>`，内存与文件状态保持一致（切换失败不改文件） |
| 目标超过上限 | 拒绝新增并提示上限，允许继续取消已有标星 |
| 目标 ID 非法 | 拒绝写入 |
| 失效目标 | 保留文件条目，导航隐藏 |
| 关注分组存在但无有效项 | 不渲染分组标题 |
