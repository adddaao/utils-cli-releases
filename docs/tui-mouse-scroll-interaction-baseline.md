# TUI 鼠标与滚轮交互基线

> 本文档是 TUI 鼠标与滚轮行为的唯一核心规范。Shell 布局与通用尺寸契约见 [TUI Shell 与布局开发基线](tui-shell-layout-development-baseline.md)，公共组件接入清单见 [TUI 公共组件接入规范](../internal/tui/components/README.md)。

## 1. 交互目标

TUI 采用 lazydocker 风格的补充式鼠标交互：鼠标在哪个面板，滚轮只作用于该面板；左键只聚焦、定位、勾选、点击面包屑返回已访问节点，或在导航菜单里进入下一级，不执行操作、不确认、不关闭。内容区聚焦时左侧导航面板不接受任何鼠标事件（点击与滚轮都必须被忽略）；键盘侧的返回入口是 `r q`、`q` 与二级子模块里的 `←/→`。导航菜单（只用于进入下一级菜单或流程的功能菜单）采用两下确认：第一下左键点击只选中并记录命中行，第二下点击同一行才进入下一级；预设或键盘高亮的行也需要真正点击两次。两次点击之间不判断时间间隔；按键、滚轮、点击空白、切换菜单或离开内容区会清除第一次点击记录。提供勾选能力的列表和多选弹框中，左键单击等同 Space：定位命中行并切换该项勾选，取消勾选后仍需重新点击才能恢复。键盘交互和帮助栏注册规则以 [TUI 按键规范](tui-keybindings.md) 为准。

## 2. 事件归属与坐标

1. `MainLayoutModel` 是唯一使用终端绝对坐标的对象。它在有效的 `WindowSizeMsg` 后，基于 `theme.DocStyle`、工作台尺寸、面板边框和内容标题计算导航面板、内容面板、内容正文和帮助栏的矩形。
2. 坐标分为终端绝对坐标、面板内部坐标和内容正文坐标。shell 向导航传递导航内部局部坐标；向普通内容传递内容正文局部坐标；向弹框传递内容面板局部坐标。业务模块和公共组件不得自行推导外边距或全局偏移。
3. 鼠标事件严格按 `可见弹框 → 内容区面包屑行 → shell 命中面板 → 当前内容组件` 路由。每条事件只能由一层处理；处理后不得继续转交给背景列表或 Bubble List。
4. 未完成首次尺寸初始化、窗口小于最小尺寸、帮助栏和文档外边距均安全消费事件，不改变 UI 状态。
5. 仅左键按下、滚轮上/下按下可改变状态；移动、拖拽、释放、中键、右键和未知按钮一律消费但无副作用。终端原生文本选择由终端自身的鼠标追踪转义方式决定，应用不作保证。
6. 左侧导航面板在导航栏聚焦时响应点击、滚轮；内容区聚焦时左键单击落在该面板上把焦点交回主界面（模块选择）并定位命中的模块行，第二下点击同一行才切换模块；滚轮一律安全消费，不得聚焦导航、移动导航光标或切换模块。

## 3. 组件契约

### 3.1 Shell 与导航

- 点击导航/内容面板使用幂等的显式焦点设置，不能调用会反向切换的 `switchFocus`。
- 内容区聚焦时左键单击左侧导航面板把焦点交回主界面（模块选择）并把光标定位到命中的模块行；第一下点击不切换模块，第二下点击同一行（此时导航栏已聚焦）才切换，避免从内容流程里一次误触就切走正在进行的任务。内容区聚焦时滚轮落在导航面板一律忽略：不得聚焦导航、移动导航光标或切换模块。键盘侧同样的返回入口是 `r q`、`q` 与内容区里未声明的 `←/→`。
- 点击内容标题或面板边框只聚焦；点击列表可见行才改变光标。滚轮落在面板边框仍归属该面板。
- 面包屑是内容区标题的第一行，也是内容面板内优先命中区域：
  - 清理工具的「手动清理」「模板清理」属于当前模式，显示在右侧内容标题；面包屑只保留真实页面节点与当前执行状态，不把模式名称伪装成可点击页面。
  - 左键点击**当前节点之前的已访问节点**时，shell 用与渲染完全相同的折叠结果做命中判定，再调用当前模块的 `shell.BreadcrumbJumpProvider.JumpBreadcrumb` 返回该节点对应的流程页面。已有流程节点时不显示模块根节点；流程下标仍保留模块根为 0，避免各模块的节点映射发生偏移。
  - 焦点进入内容区后，左侧导航在当前模块名称后显示 `◆`，标明内容所属模块；焦点返回导航栏后隐藏。该标识不修改导航项名称、筛选值或面包屑路径。
  - 点击当前节点、后续节点、折叠占位 `...`、分隔符、右侧焦点状态文本和空白只保留聚焦，不改变任何状态；模块未实现 `BreadcrumbJumpProvider` 或该节点返回 `handled=false` 时同样不改变状态。
  - 窄终端下面包屑折叠后，鼠标命中的原始节点必须与屏幕显示一致：渲染与命中共用同一份折叠函数和同一份可用宽度计算，不能各自推导坐标。
  - 弹框可见时面包屑点击被弹框层完整消费，不穿透到模块。
  - 面包屑跳转只做导航：模块实现必须复用已有的“显示某页面”逻辑，不得触发执行、确认、落盘、删除或关闭；读取/执行/完成等阶段节点、终态节点和依赖上下文的节点必须返回 `handled=false`。执行中的页面（帮助栏没有返回声明的扫描、清理、导出、部署、规则更新、查找等状态）也必须拒绝返回，避免正在进行的操作失去可视目标。
  - 下标与顺序规则只有一份：`shell.ResolveBreadcrumbJump` 负责把点击下标解析成「模块根」或「流程节点文案」，并拒绝空流程、越界、当前节点和后续节点；模块只提供 Root / Label 到自身页面的映射，不允许各自重复实现下标换算、越界判断或从 `Steps` 反推页面。
- `internal/tui/components/mouse` 只提供矩形、局部化与按钮判定，不能出现导航、内容或帮助栏等工作台概念。

### 3.2 列表

- `components/list` 是唯一的 Bubble List 鼠标选择/滚轮实现；`UnifiedPageModel` 和业务私有列表调用该能力，不能复制游标循环或点击坐标逻辑。
- 每个被接受的滚轮消息移动一项并循环；触控板或终端在一次手势中密集发送的重复滚轮消息必须由 `MouseWheelGate` 消费，不能让光标跳项。`Filtering` 输入态不改变选择，`FilterApplied` 必须以 `VisibleItems()`、当前 paginator slice 为准，不能按原始 `Items()` 长度计算。
- 点击映射必须包含当前页首项、delegate 高度/间距、列表 chrome、`SetListHeader` 和 `SetListFooter`；标题、状态、分页、帮助和 footer 不是可选择行。
- 提供勾选能力的列表（如镜像导出/上传选择、归档选择、清理确认）必须用 `ClickedListItemAtPoint` 取得命中索引，然后切换该行勾选；`UnifiedPageModel.HandleSelectMouse` 是这类列表的统一入口，模块只能用它，不能再自己推导点击坐标。
- 只用于“进入下一级”的导航菜单（模块功能菜单、子菜单、模式选择）用 `UnifiedPageModel.HandleMenuMouse` 或带 `MenuClickTracker` 的 `ClickedRowConfirm`：第一下点击只选中并记录命中行，第二下点击同一行才等同 Enter 进入下一级；预设高亮行也必须点击两次，中间不判断时间间隔。按键、滚轮、未命中行、菜单重建与失焦均清除点击记录。
- 操作菜单、确认/清理页和数据列表继续用 `SelectListItemAtPoint` 或 `HandleMouse`：左键只定位，执行仍由键盘确认，避免鼠标误触启动、停止、删除、清理和落盘。
- 勾选列表与多选弹框不使用两下确认，保持单击即勾选：批量勾选场景下两下确认会让鼠标操作成本翻倍。
- 滚轮只改变光标，任何鼠标位置变化都不能顺带勾选、取消勾选或进入下一级。
- Bubble List 启用筛选能力时，即使标题和筛选框当前不可见，仍可能渲染隐藏的标题区间隔；命中测试必须复用 `ListItemsRect`，不得自行假定首项从 Y=0 开始。需要构造真实命中时使用 `UnifiedPageModel.ListItemsRect()`。
- 所有鼠标引起的选择变化都要清空编号输入缓冲，之后仍需 `Enter` 才能执行。

### 3.3 弹框

- `ModalListModel.UpdateMouse` 对可见弹框始终返回已消费。框外点击不关闭、不穿透；普通弹框点击可选行只定位，多选弹框点击可选行同时切换该项勾选（等同 Space），内容弹框左键无动作。
- 弹框渲染与命中测试共享同一布局函数和同一面板构造函数；`MouseBounds()` 返回当前局部边界，resize 后无需依赖上次 `View()` 的旧坐标。
- 普通弹框滚轮按一项循环移动；内容弹框滚轮按三行滚动，且不改变任何勾选。

### 3.4 执行视图与实时日志

- `TaskExecutionModel.HandleMouse` 按 Y 坐标命中任务表或日志区：滚轮只滚命中的 viewport，左键只切换该子区焦点。
- `logviewer.Model.HandleMouse` 只接受日志面板范围内的滚轮；到达顶部仍返回 `ActionLoadOlder`，由业务模块加载历史日志。
- 输入表单、路径建议、历史建议、密码和令牌编辑态不支持鼠标定位或候选选择；鼠标不应泄露敏感值或改变编辑内容。

## 4. 模块接入清单

| 模块 | 列表 | 执行/日志 | 弹框 | 表单/详情 | 面包屑返回（已访问节点） |
|---|---|---|---|---|---|
| Docker | Unified 列表 | 执行视图、容器日志 | 全部 `GetModal()` 弹框 | 消费不操作 | 模块根；`选择功能`、一级菜单、镜像/容器/网络/磁盘/信息/Compose 等只读功能页；有容器上下文时的只读工作台页（详情、日志、监控、进程、生成命令、运行参数、文件复制、提交配置） |
| Clean | Unified 列表 | 执行视图 | 规则与明细弹框 | 消费不操作 | 模块根、模板列表、模板本次清理路径、手动清理参数页、已有扫描结果的只读扫描结果页；扫描/清理执行中不响应 |
| Database | Unified 列表 | 执行视图 | 数据库选择弹框 | 消费不操作 | 模块根、类型/功能/备份/用户与数据库菜单、导出/导入参数页、备份计划与选择计划/选择文件页；执行中、预检中、编辑中不响应 |
| Find | 私有列表 | 执行视图 | 无 | 消费不操作 | 模块根、模板列表/参数/预览、历史列表/详情（缺上下文不响应）、自定义路径/类型/条件/动作/预览、条件编辑器；查找执行中不响应 |
| Firewall | 私有列表 | 无 | 无 | 消费不操作 | 模块根、按当前操作回到端口输入页、端口规则读取页；读取弹框可见和规则更新未结束时整体不响应 |
| AIOps | 私有菜单 | 执行视图 | 选择弹框 | 消费不操作 | 模块根、各功能首页（选择服务器/项目弹框、只读概览页）；执行中、只读读取中、编辑中不响应 |
| FileExport | 私有菜单 | 执行视图 | 无 | 消费不操作 | 模块根、导出参数页、别名参数页（保留已填草稿）；执行中、编辑中不响应 |
| Tools | 私有菜单列表 | 无 | 无 | 消费不操作 | 模块根、生成参数表单；生成结果是终态节点不响应 |

每个模块的具体节点文案到页面映射由该模块的 `breadcrumb_jump.go` 维护；跨模块共用的只有 `shell.ResolveBreadcrumbJump` 的下标/顺序规则和 shell 的命中路由。

导航菜单左键单击进入的接入范围：Docker 的选择功能与各级菜单及 Compose/文件复制模式选择、Clean 模式选择、Database 类型/功能/备份/用户与数据库菜单、AIOps 主菜单、Find 主菜单与文件类型选择、FileExport 主菜单、Tools 主菜单。这些菜单都是两下确认（第一下选中、第二下进入）。操作确认菜单（容器启动/停止、清理确认、删除确认）、数据列表和勾选列表不在其中，仍只定位或单击即勾选。

`shell/MainMenuModel` 是未接入运行入口的 legacy 模型，不纳入鼠标能力承诺。

## 5. 验证要求

1. 单测覆盖矩形坐标、支持动作、面板命中、首次尺寸前安全消费、显式焦点设置和单次事件消费；内容区聚焦时左侧导航面板的点击与滚轮必须被忽略（焦点、导航光标和当前模块都不变），用 `r q`/`q`/二级子模块里的 `←/→` 回到导航栏后导航面板恢复响应。
2. 列表测试覆盖首尾循环、分页、筛选输入、已应用筛选、隐藏筛选标题区、header/footer、窄宽度和多列宽文本，以及勾选列表左键单击定位并切换勾选、导航菜单第一下只选中/第二下进入下一级（与 Enter 同状态）、点击列表空白区域和滚轮不进入下一级、滚轮不改变勾选；菜单路径必须同时有模块内单测和经过真实 Shell 分发的整屏点击回归。
3. 弹框测试覆盖普通/多选/搜索/内容弹框、框内外点击、滚轮、resize 后立即操作和背景不变；多选弹框的点击必须验证定位与勾选同时发生，单选弹框的点击必须验证不产生勾选。
4. 执行与日志测试覆盖任务表/日志区分别滚动、左键切换焦点、日志顶部历史加载。
5. 修改后必须执行 `make test`、宿主平台对应的 `make build-mac` / `make build-linux` / `make build-windows` 和 `make temp`；人工验证所有已注册模块及所用终端的文本复制方式。
6. 面包屑测试必须覆盖：`shell.ResolveBreadcrumbJump` 的空流程/越界/当前/后续下标判定、命中判定与渲染共用同一份折叠结果（含窄宽度折叠占位不可点击）、分隔符与状态区不命中、只有当前节点之前的节点可返回、弹框打开时不穿透、模块未实现返回能力时状态不变，以及每个模块至少一个“节点 → 目标页面”返回结果和执行中不响应。
