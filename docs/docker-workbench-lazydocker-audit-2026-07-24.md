# Docker 工作台 LazyDocker 体验审计

日期：2026-07-24

## 目标

借鉴 LazyDocker 的排障闭环和信息密度，不复制其界面样式；保留本项目的拟态弹框、公共表格、执行视图与工作台流程。

## 审计范围与结论

| 路径 | 结论 | 本轮处理 |
|---|---|---|
| 容器选择 | 支持运行中筛选、搜索、编号定位和当前项概览 | 保留；概览与完整详情职责分离。 |
| 选中容器工作台 | 已保留容器上下文，但运行摘要原先纵向占用过多 | 改为单行摘要表，给操作列表释放垂直空间。 |
| 完整详情 | 原先 `i` 是弹框，菜单“完整详情”可能跳独立页面 | 统一为拟态弹框；基础信息、运行配置、环境变量、挂载、网络与标签均在弹框内滚动查看。 |
| 鼠标与滚轮 | 内容弹框的滚轮没有被路由，背景列表可能接收鼠标事件 | 公共内容弹框支持滚轮；弹框打开期间消费鼠标事件，背景不会误响应。 |
| 实时日志 | 已有跟随、暂停、筛选、换行、水平滚动和按需回溯 | 保留现有公共日志查看器，不重复实现。 |
| 资源监控 | 已有实时采样、暂停、刷新、频率和 CPU/内存/网络/磁盘趋势 | 保留现有趋势仪表盘；操作页可直接进入当前容器监控。 |
| 生命周期操作 | 已有确认弹框、执行日志与完成态 | 保留覆盖式执行交互，避免丢失当前容器上下文。 |

## 用户可见行为

1. 容器列表中的 `i` 打开轻量“当前容器概览”。
2. 选中容器后的 `i` 或“完整详情”菜单都打开同一个“容器详情”拟态弹框，不跳转页面。
3. 详情弹框可用 `↑↓`、`PgUp/PgDn` 或鼠标滚轮浏览；底部会显示当前行范围。
4. 环境变量、密码和令牌显示原始值，便于复制；左键不会关闭弹框。
5. 弹框存在时，滚轮和鼠标事件不会传递到背景容器/操作列表。

## 验收

- 公共内容弹框单测覆盖键盘滚动、鼠标滚轮和关闭行为。
- Docker 工作台测试覆盖完整详情弹框、详情入口复用、背景状态保持和详情内容刷新。
- 全仓质量守卫与 `make test` 通过；构建与差异检查在本轮收口时执行。

## 不在本轮范围

- 内嵌交互 Shell。
- 原始 Docker Inspect JSON。

这些能力与“结构化排障工作台”是不同的产品边界，继续沿用既有 backlog 管理。
